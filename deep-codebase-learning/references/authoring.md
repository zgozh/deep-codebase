# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还后才开始首次通读。有实质新状态才通信，优先宿主完成通知或有界等待；不频繁 poll/list，不每次等待后另列 agent 状态，轮询次数不能证明作者空闲。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节问题与主链；读真实源码及必要适用官方章节，先按 [十章教材骨架](../assets/templates/stage-note.md) 建好教学次序，再写完整可读稿。第五章按问题/调用输入→完整源码→代码后所有行的细致正文→边界和局部回放→真实用法/上下游/接入逐个展开。概念先短释再详细教，第六章深化机制，不接收延期前置。具体缺口随写随查，不等全仓精读，不另造资料汇编或审查稿。已读未变 Skill/模板/资料复用，不能凭缓存猜源码。

开写前在已有当前 stage、稿件开头或委派任务放四行 brief，不另建备课文件：

- 本节因果目标与起止符号。
- 必追的具体值、调用和交接。
- 此节必要前置与适用版本规则。
- 明确留到后续的内部机制及返回点。

只读主链和必要直接依赖，先完整稿再定点补查，不预读全项目、全部文档或所有失败模式。同一次通读先从读者角度复演关键正常及本目标重要分支，再核真实调用处的语法与上下文，缺口修正文；不是新增审查轮次。

完整稿实际从头做一次语义通读：single 作者自查，delegated 主会话自身独立读子稿，不只听作者报告。在同一次阅读中独立判断两个维度：事实是否正确，初学者是否读得懂。前者核源码原行与内容、版本、具体条件/数据/状态/消费者及官方映射；后者只凭正文看每个新概念是否先讲后用并充分展开，所有贴出行是否对应足量解释，框架步骤/用法/接入/取舍是否讲明。审核者自己懂不能填补文章漏讲；事实无错也可能浅，读起来通顺也可能造了源码。十章标题、篇幅、注释数或作者报告都不能通过。缺口定点修正文，不另造检查矩阵、JSON 质量契约、hash 仪式或第二套门禁工具。回读最终展示首尾，防止补丁/过期交接混入正文。

按 [笔记协议](notes.md#note-quality-gate) 简记真实方法、范围、具体缺陷及修复位置、未核实项。single 合格稿记 ready/self_review，delegated 经真实独审的范围可 validated；均可 delivered，不代表实测/用户能力。必要 V0 包括 UTF-8 回读、围栏配对、相关链接/索引/JSON 与指针；本地链接还须读目标内容确认支持相邻断言，不能只验行号在界内。源码原行与该版内容匹配另核。无应用改动不跑应用测试/构建/浏览器；未变有效证据不重复。保存索引与实际学习变化后简短给主题、范围和链接，问题直接充分答疑。

## 返修保留教学内容

先确认一份可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。按 [内容保留合同](teaching.md#返修保留教学内容) 局部修缺陷，保留正确必要解释，并复读改动及上下游、对照是否丢教学单元。删错/重复给具体依据；迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿则说清保留核对边界，不把摘要当完整返修。需要多解释时写足，收无关旁支不收深度。

在同一 review 短记具体缺口和修复位置；发生实质删改/迁移时说明原因与正确必要解释的保留去向，不另建逐段矩阵/hash 报告。只补局部就读改动及影响链，不重新验未变全文；广泛重写或影响不明再全文读。不用缩字目标、KB 或章节数判断深度，允许有依据地删错/重复。

仅广泛重写、源码范围大变或影响不明才全文重读；局部改字/状态收尾不使所有结论自动失效。简记实际复核范围，差异按标题/具体范围读取，不反复输出整篇 diff；不逐段复制证据表，不为每次返修新造报告。delegated 返还同一作者具体位置/依据/目标，作者交稿后主会话复读影响链；必要解释未补齐仍 draft，不能为交付好看编通过。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者失败/超时时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；恢复不依赖旧子会话。

Windows 中文显式 UTF-8，Python 检查用 `-X utf8`。补丁匹配失败刷新实际局部，换唯一短锚点或安全局部替换；传输/编码失败先换可靠文件工具/apply_patch，不原样重试长命令、不重新研究全项目。收尾用实际当前局部短锚点，集中写本次必要 projections，不为匹配失败重读整篇。必要源码与官方规则查证仍须完成，不能当作浪费删掉。回读成功前不声称已保存，依赖保存的跨 Topic 推进仍须等待保存成功。
