# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还后才开始首次通读。有实质新状态才通信，优先宿主完成通知或有界等待；不频繁 poll/list，不每次等待后另列 agent 状态，轮询次数不能证明作者空闲。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节问题与主链；读真实源码及必要适用官方章节，按 [十章教材骨架](../assets/templates/stage-note.md) 尽早写一份完整可读稿。首次完整课或重大反馈时按正在写的章节读 [小型完整功能读码示例](quality-example.md) 的相关写法，确需整体对照才读整例；已读未变内容复用。它不是大型全栈代表课或真实课尺寸上限，历史 helper 只供局部语法校准。示例的语言、版本和业务事实按真实技术栈核实；概念先短释再深入教，第六章深化机制，不接收延期前置。必要资料缺口随写随查，不等全仓精读，不另造资料汇编、过程文档或审查稿；不能凭缓存猜源码。

开写前在已有当前 stage、稿件开头或委派任务放四行 brief，不另建备课文件：

- 本节因果目标与起止符号。
- 必追的具体值、调用和交接。
- 此节必要前置与适用版本规则。
- 明确留到后续的内部机制及返回点。

同版本规范、模板与证据在当前上下文只读一次，丢失或变化才按需恢复；只读主链和必要直接依赖，不重复全仓搜索。作者先定 frontmatter 等元数据，交还时一并冻结正文与元数据，审读期间不并行改同稿。通信优先宿主完成通知，有实质更新才发送消息，不把等待与 list 组合成重复轮询。

完整稿做一次内容审读：single 作者自查，delegated 主会话自身独立读稿。同一次语义通读实际覆盖 [十章表](teaching.md#唯一教学交付合同) 的每章全部相关职责，以及 [源码单元合同](teaching.md#第五章源码之前源码之中源码之后) 的每个行为单元八项固定职责。确认单元按初始化和用户动作的因果次序组织，有自己的问题/输入准备，完整必要源码及所有行的正文推导，并在本单元教局部运行、重要失败、机制与接入；不以第六至八章补缺。少数难点成功、全链正确或代表性证据不能代替其余单元的核查。所有章从初学者出发核概念、示范、推导、实值例子、定位和可读性；第九章答案有推导/回指，第十章有未知/下一课/能力边界。真不适用说明具体原因，不虚构。

在同一次阅读中，对照所贴有意义行，只凭当前单元的代码后正文还原语法、实参/形参、函数/API 职责与调用位置、返回/消费者、框架介入时机和项目接入口、必要底层机制及设计判断；核其是否结合当前文件和真实调用链，先讲本次具体接线再解释实际相关知识，集中讲的跨行机制须映射回来。发现新 API、关键语法、调用或设计只见名称/注释/标题、通用释义、或靠审读者经验才能解释，就指出对应语句和缺失教学并修该处，不用后章或作者自评补过。再从正文复演真实使用、架构协作、同值正常/重要失败全链，并核原行/内容/版本、状态/消费者与官方规则及链接支持。源码事实正确不等于教得充分，示例偏小或不完整不构成真实课尺寸上限或交付达标证据；缺漏修正文后复读影响范围，不另起流程或工具。

在现有 [review](../assets/templates/review.md) 简记实际通读范围、最关键的具体缺漏及修复位置和真实未核范围，区分源码保真/知识事实与教学展开的结论。记录可以少，核查必须覆盖每个行为单元；只抽查就写抽查范围，不声称整课合格。缺哪小节任务就具体指出并修正文，不大段复抄或造逐单元矩阵。定位优先稳定章节/符号，必要时给准确局部行，不维护教材总字节/hash 作为品质字段。必要教学缺失仍 draft；合格 single 记 ready/self_review，真实独审范围才可 validated。有限静态试用不替代用户明确验收，不证明应用、模型长期稳定或真实学习效果。

收尾一次完成必要文档 V0：UTF-8 安全回读、围栏及相关链接/索引/JSON/指针，复用未受影响的有效检查。回读最终展示首尾防止补丁/过期交接混入。明确跳过应用检查时不运行；无应用改动不跑应用测试/构建/浏览器。通过后由主会话集中更新一次必要索引/state/stage/journal，再简短交付主题、范围和入口；有价值问答及中断仍及时保存，不等整稿完成。

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。补缺须重组受影响单元，让问题、输入准备、源码、逐行推导、演算、机制和接入各在对应小节，不能只追加散段反复解释。按 [内容保留合同](teaching.md#返修保留教学内容) 读实际 diff，保留有效源码、准确教学注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或实质重复给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿说清边界；不为提速缩深度或用自动摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改/迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵/hash 报告。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的有效证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。delegated 返还同一作者具体位置/依据/目标，作者交稿后主会话复读相应范围；必要解释未补齐仍 draft，不能为交付好看编通过。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者失败/超时时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；恢复不依赖旧子会话。

Windows 中文显式 UTF-8，Python 检查用 `-X utf8`。首次传输/编码或补丁锚点失败立即换可靠 UTF-8 写入方式，仅恢复必要局部锚点，不原样重试长命令、不重做分析。收尾集中写本次必要 projections，不为匹配失败重读整篇。必要源码与官方规则查证仍须完成，不能当作浪费删掉。按实际落盘阶段汇报，回读成功前不声称已写完或保存，依赖保存的跨 Topic 推进仍须等待保存成功。
