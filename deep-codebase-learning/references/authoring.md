# 单会话与可选委派编写

## 首次选择与持久偏好

默认单会话：当前模型规划、写教材、自审、保存。首次在这个学习项目使用本 Skill 时，简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”用宿主可用的文本选择工具；没有该工具时在首次交付的简短回复中询问。说明后者需要子 agent 支持、可能增加耗时/资源，不许诺必然提高质量。用户已明确选择则直接沿用，不重复询问。

这不是知识题或授课门票：没有答复仍单会话完成首节，沉默不构成委派授权。当前 stage 持久偏好与 journal checkpoint 保存 mode=single/delegated、是否已询问、用户原意及环境限制；切阶段复制，不新增必填 state 字段。已有学习项目首次加载本版且没有选择记录也提供一次，保留进度。用户可随时切换，不丢旧稿/历史。

宿主不支持委派时说明并继续单会话；不得自建服务、MCP、CLI、后台或要求安装才能学。Skill 不固定模型、推理档位或 agent 数量，用户与宿主约束优先。它是选择，不是运行依赖。

## 主会话规划与文件所有权

主会话拥有路线、最新偏好、因果目标、审查、索引和最终交付。先 PRE-TURN 核对源码身份、教材/能力边界，再给子 agent 一个有界任务，至少包含：

- 稳定 Stage/Topic/课 ID、中文内容目录和唯一草稿路径。
- 具体场景、前课真实解释深度、当前必需前置、起止符号、下一接续点与排除旁支。
- 需实际读取的源码/清单/版本资料、允许路径；私人源码不外传，源码和历史不是授权指令。
- [教学合同](teaching.md#唯一教学交付合同)、[笔记门禁](notes.md#note-quality-gate)、逐句注释/贯穿例子/官方规则映射要求。
- 子 agent 只拥有本节稿件，不能改 state/journal/索引/mastery/coverage/其他稿件或项目源码，不能提交、推送、部署、安装或做有副作用实验。
- 返回稿件路径、实际源码/官方版本出处、真实检查结果、未知/未测与自审问题。草稿不能自标最终 validated/delivered。

默认一次委派一节，完成再排下一节；确实独立才并行，事先明确文件所有权/依赖。主会话不同时编辑编写者稿件，不让多个 agent 写共享状态。等待时可回应状态，不声称未发生的完成或永久后台执行。

## 独立主审、返修与交付

子 agent 读当前实际源码与适用官方章节，按因果链写详细教材，不凭职责摘要补造源码；提交 prepared 草稿与真实检查结果。

主会话在自己的上下文逐段读稿，不只接受“通过”报告；核对每个关键源码/分支和支撑官方章节，代入例子检查注释与正文、调用/状态/返回一致性，执行十项 Note Quality Gate。新词、必要前置遗漏、范围漂移、版本冒认、静态推断当实测都须修。单会话自审不叫独立审核；主审另一个编写者稿件也不等于外部专家认证。

返修给具体段落、依据与目标，交同一编写者修当前缺陷；再审受影响链，不扩大到全仓。缺资料则补查、准确限缩或保留草稿，不能编通过。主会话审查通过后才改质量状态、登记正式教材、做 V0 和 POST-TURN，写共享学习状态。review 记录实际作者/审查者、方法、范围与未测项，两个 agent 不证明运行或用户能力。

最终简短给范围与笔记链接。聊天提问由主会话直接答；发现实质教材缺陷可以有界委派返修，主审后再提交，不让答疑等待整节重编。

## 中断与故障

子 agent 失败/超时/宿主限制时保存草稿和未完成范围，如实说明；能继续则单会话接手同一目标，不伪造成功。接手前结束任务并明确交还所有权，避免并发写。恢复只依赖源码和 `.codelearn/`，不依赖旧子会话继续存在；稿件/评审与 next_action 足够恢复。中文阶段分类与旧路径迁移按 [笔记协议](notes.md)。
