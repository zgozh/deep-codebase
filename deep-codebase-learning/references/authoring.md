# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还后才开始首次通读。有实质新状态才通信，优先宿主完成通知或有界等待；不频繁 poll/list，不每次等待后另列 agent 状态，轮询次数不能证明作者空闲。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节问题与主链；读真实源码及必要适用官方章节，将本节问题、真实符号和输入在下述既有 brief 中绑定到 [十章教材骨架](../assets/templates/stage-note.md) 的实际小节任务，委派也不能只说“遵守 Skill，详细写”。按单元厚写：一段完整职责或连续源块连同对应逐语义组充分正文连续成稿，再进入下一块/单元；非源码章同样在对应小节落实具体例子、因果与机制。不能先贴齐全部代码、给全章各填几句概述占位，再把补深留到末尾。尽早形成完整可读稿，内部写作顺序不改变读者的十章次序，最终仍一次完整稿通读，不新增逐单元移交门禁、文件或备课矩阵。首次完整课或重大反馈时按正在写的章节读 [小型完整功能读码示例](quality-example.md) 的相关写法，确需整体对照才读整例；已读未变内容复用。它不是大型全栈代表课或真实课尺寸上限，历史 helper 只供局部语法校准。示例的语言、版本和业务事实按真实技术栈核实；概念先短释再深入教，第六章深化机制，不接收延期前置。必要资料缺口随写随查，不等全仓精读，不另造资料汇编、过程文档或审查稿；不能凭缓存猜源码。

开写前在已有当前 stage、稿件开头或委派任务放四行 brief，不另建备课文件：

- 本节因果目标与起止符号；本轮采用的 Skill 版本。
- 必追的具体值、调用和交接。
- 此节必要前置与适用版本规则。
- 明确留到后续的内部机制及返回点；最新反馈事件与对本稿的具体影响。

同版本规范、模板与证据在当前上下文只读一次，丢失或变化才按需恢复；只读主链和必要直接依赖，不重复全仓搜索。作者先定 frontmatter 等元数据，交还时一并冻结正文与元数据，审读期间不并行改同稿；冻结与终审都核最终稿已吸收 brief 所列版本要求和最新反馈。中途规范或反馈变化只重开受影响内容，不重启整课。通信优先宿主完成通知，有实质更新才发送消息，不把等待与 list 组合成重复轮询。

完整稿做一次内容审读：single 作者自查，delegated 主会话自身独立读稿。同一次语义通读实际覆盖 [十章表](teaching.md#唯一教学交付合同) 与 [章内展开模板](../assets/templates/stage-note.md) 中每章实际小节的全部适用职责，以及 [源码单元合同](teaching.md#第五章源码之前源码之中源码之后) 的每个行为单元八项固定职责。按模板入口的内容优先原则核合并/回指/不适用的真实依据和保留位置，当前必需含义、机制和具体值须已落实，否则仍 draft；不因小节名或一句章节职责通过，不为每小节另起审查记录。确认单元按初始化和用户动作的因果次序组织，有自己的问题/输入准备，完整必要源码及所有行的正文推导，并在本单元教局部运行、重要失败、机制与接入；不以第六至八章补缺。少数难点成功、全链正确或代表性证据不能代替其余单元的核查。所有章从初学者出发核概念、示范、推导、实值例子、定位和可读性，并核能否据真实约束作开发与架构判断；第九章答案有推导/回指，第十章有未知/下一课/能力边界。真不适用说明具体原因，不虚构。

在这一次通读中逐块对照代码与紧邻的代码后正文，沿求值/行为边界检查每个有意义语句，不能只看八项标题或全链。只凭正文还原实际语法、变量来源和求值、具体调用时点与实参/形参绑定、返回或对象状态的消费者、条件/提前返回与失败停止，再核正文能否解释当前相关语言/API/框架底层机制及实现判断。集中教的共同机制须映射回当前语句与值；靠审读者自身经验补出的步骤就是漏讲。发现只见名称、注释、标题、通用释义或整段用途时，指出实际表达式、缺少的解释及应修正文位置。与此同时核原行/内容/版本、真实调用与状态/消费者、适用官方规则和链接支持；再从正文复演真实使用、架构协作及同值正常/重要失败全链。事实正确与教学充分分别判断，示例大小不构成真实课尺寸上限或达标证据；不另起流程或工具。

通读时积累核查结果，完成后一次写入现有 [review](../assets/templates/review.md)：十章各一条短普通列表，第五章另对实际每个5.x行为单元各一条，不逐语义组写盘、不另建文件。每条分别记事实与教学的已核/未核/待修或待补；每章一条内注明实际已核小节范围和具体正文落点或缺陷，待修项指出实际表达式或论述、缺少解释及修复位置，未核明确到实际小节/范围。稳定章节/符号优先，必要时给准确局部行。短记录用于显露实际已核、未核和待修范围，不能单凭范围文字或记录证明审查确已完成，核查仍须覆盖每章各小节和每个行为单元全部适用职责；一条“全课通过”、少量清单、抽查与调用链正确均不能吞掉未核内容。不做每小节多维记录或每行×八职责的大矩阵，不重复抄教材/报告，不维护教材字节/hash 品质字段。任一必要范围未核或教学未补齐，整课仍 draft，局部通过不能整体升级；只抽查就限定结论。合格 single 记 ready/self_review，真实独审范围才可 validated。局部修复只复读影响链并更新相应短记录，复用未受影响证据。有限静态试用不替代用户明确验收，不证明应用、模型长期稳定或真实学习效果。

收尾一次完成必要文档 V0：UTF-8 安全回读、围栏及相关链接/索引/JSON/指针，复用未受影响的有效检查。回读最终展示首尾防止补丁/过期交接混入。明确跳过应用检查时不运行；无应用改动不跑应用测试/构建/浏览器。通过后由主会话集中更新一次必要索引/state/stage/journal，再简短交付主题、范围和入口；有价值问答及中断仍及时保存，不等整稿完成。

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。补缺须重组受影响单元，让问题、输入准备、源码、逐行推导、演算、机制和接入各在对应小节，不能只追加散段反复解释。按 [内容保留合同](teaching.md#返修保留教学内容) 读实际 diff，保留有效源码、准确教学注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或实质重复给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿说清边界；不为提速缩深度或用自动摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改/迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵/hash 报告。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的有效证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。delegated 返还同一作者具体位置/依据/目标，作者交稿后主会话复读相应范围；必要解释未补齐仍 draft，不能为交付好看编通过。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者失败/超时时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；恢复不依赖旧子会话。

Windows 中文显式 UTF-8，Python 检查用 `-X utf8`。首次传输/编码或补丁锚点失败立即换可靠 UTF-8 写入方式，仅恢复必要局部锚点，不原样重试长命令、不重做分析。收尾集中写本次必要 projections，不为匹配失败重读整篇。必要源码与官方规则查证仍须完成，不能当作浪费删掉。按实际落盘阶段汇报，回读成功前不声称已写完或保存，依赖保存的跨 Topic 推进仍须等待保存成功。
