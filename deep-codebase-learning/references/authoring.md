# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型或推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件或指定独占 part，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交、不部署、不安装、不做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景与目标、前课真实解释深度、必要源码与官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同一 part 只一人写，移交后再编辑；默认一次一节。作者停止写稿并交还冻结范围后，主会话才开始独立审读。优先宿主完成通知；需主动等待时选一种有界机制，同一任务无新状态时不交替 sleep、wait、list 重复确认。等待超时只表示本次未收到更新，不证明作者失败或空闲；不以固定等待次数截断必要编写或审读。

## 源码写法输入

源码写法默认只读当前匹配的完整示范段：字面读法、类型及嵌套函数值绑定，读 [语句精读对照](source-unit-example.md#语句精读对照java函数值与结果接收) 的真实教学代码及全部相邻正文；框架机制或全单元布局需要时，再按需读同文 Flask 完整 AuthActions 单元，不默认叠加两种全文。七 H4 与八职责布局仍由 [canonical 模板](../assets/templates/stage-note.md#5x-真实符号本单元具体行为) 承担，[旧完整功能示例](quality-example.md) 仅在整课布局需要时参考。匹配段已读且未变就复用，否则完整读该段，不 head+tail 跳过解释。只迁移展开方法，Java/Python 事实不套目标语言，真实语法与 API 仍核目标源码与适用官方规则；示例尺寸不是课程上限。纯非源码课不强插，不另写样稿或增加审读轮次。

选源码范围时沿具体值或函数找到实际产生/创建、登记/适配、调用/回调及消费表达式：决定本课对象、类型、状态或控制结论的最小完整实现必须进入源码教学，只给依赖路径和用途不算完成；真正只需接口的旁支仍交代边界与接续，不追整套框架。需要加载的 [源码之中](teaching.md#源码之中完整真实职责与教学注释)、[源码之后](teaching.md#源码之后值链机制判断) 与 [执行机制与数据](teaching.md#执行机制与数据要讲到哪里) 按当前单元实际读取，不预读整套规范。落笔执行方式见 [写作入口](write-lesson.md)。

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。已跟踪稿用 Git 差异；ignored/untracked 的已有稿与该可恢复版本比较，例如 `git diff --no-index` 返回 1 表示内容有差异，超过 1 才查实际错误。空仓库 diff 不算原稿保留证据，不为比较 git add 或改 ignore；新稿直接读实际内容，不造旧稿。补缺须重组受影响单元，让问题、输入、源码、推导、演算、机制和接入各在对应小节，不只追加散段。按 [内容保留合同](teaching.md#返修保留教学内容) 核实际差异及影响段，保留有效源码、准确注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或去实质重复要给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿时说明边界，不为提速缩深度或用摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改或迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵或 hash 报告。冻结范围结束后，把已知事实与教学缺口汇成一次有边界的返修任务，给同一作者具体位置、缺失推理及正确必要内容的保留要求；不先退几个错，再把同轮已见漏项另轮下达。读冻结稿期间不穿插作者编辑。若结构性问题已阻断余下审读，明确已读和未读范围后交回，不冒称全篇通过。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的审读与 V0 证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。

## 中断、记忆与写入故障

同一冻结稿收齐语义缺口后只发一批集中修正，再审受影响范围；同根因反复出现时停止救稿，保留 draft 并将本次工作流记 FAIL，不靠无限微补改成 PASS。必要事实与教学错误仍如实标明待修，另行恢复不能抹去原失败；可选措辞不重启整条流程。

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者实际失败或任务被宿主终止时如实保存现稿与未完边界，结束任务并交还所有权后可由 single 接手；一次等待超时不触发接管，恢复不依赖旧子会话。

### 写入传输与局部恢复

首次写入或返修前实际读取 [写入约定](writing-io.md) 的当前必要正文；发生写入故障时按其分类恢复，已读未变内容复用。source include、渲染与安全原文保存路径在该小页，无需为写入加载整个编写流程。
