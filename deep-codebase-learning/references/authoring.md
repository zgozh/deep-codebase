# 单会话与可选委派编写

## 首次选择与持久偏好

默认 single：当前模型规划、写教材、作者自查、保存完整待独审可读稿。首次在这个学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”用宿主可用文本选择工具；没有工具时在首次交付回复中询问。delegated 需要子 agent 支持，可能增加耗时/资源，不许诺必然提高质量。已有明确选择直接沿用；没有答复仍 single 完成首节，沉默不构成委派授权。

模式不是知识测验或授课门票。当前 stage 与 journal checkpoint 保存 mode=single/delegated、是否已询问、用户原意和环境限制；切阶段继承，不新增必填 state 字段。已有项目无记录也提供一次，保留进度。用户可切换，宿主不支持委派则说明并 single 继续，不自建服务/CLI/后台或要求安装。Skill 不固定模型、推理档位或 agent 数量。

## 作者所有权：完整初稿后定点查证

主会话拥有路线、偏好、因果目标和共享学习状态。作者拥有本节唯一稿件，先恢复真实边界、确定一组贯穿输入及段落骨架，只读主链和必要直接依赖，随步骤写出完整可读初稿。将缺少的源锚点/官方机制放备课记录；初稿形成后针对具体缺口补查，不在正文尚未开始时无限扩大资料预读。必要解释未查明则保留 draft，不能靠 unknown 敷衍。

用户选择 delegated 才给子 agent 有界任务：稳定 Stage/Topic/课 ID、中文目录、唯一稿路径、前课实际解释深度、具体场景/输入、起止符号、必要前置、接续点、排除旁支、允许读取的源码/版本资料与 [教学合同](teaching.md#唯一教学交付合同)。子 agent 只写该稿，不改 state/journal/索引/mastery/coverage/其他稿件或项目代码，不提交/推送/部署/安装，不做未授权副作用实验，不将私人源码外传。默认一次一节；独立并行必须先明确各稿所有权与依赖，不能多人写共享状态。

## 冻结、独立主审与返修

1. 作者完成一次集中自查和 V0 修稿，将稿标 draft；提交实际路径、源码/官方出处、未测项、待解决问题。冻结身份记录在 review：实际内容 hash（用宿主计算的 SHA256）或可从版本库取回原文的实际版本，连同路径和检查范围。默认 hash 对明确起止的教学正文计算，排除顶部状态/审核元数据；记录范围及编码，保留可核验该版正文，不能只写“正文hash”。状态收尾可更新元数据而不改变所审正文，源码版本、边界等事实元数据也须在 G0 核对，改动需复核。不手写假 SHA；dirty 文件不能只用 HEAD 冒充内容身份。冻结后作者停止编辑并交还所有权。
2. 独立审核者先在自己的上下文全文冷读该版，不接受作者自评代替阅读；按 [G0/G1/G2](notes.md#note-quality-gate) 写可重建的路径答案和文章位置，再回源核事实。主会话审子稿须自身独立读全文，不能只挑关键片段或转述子 agent 的结论。single 作者自查不能充当独审；没有独审仍可提供完整待独审稿并编写下一节。
3. 审核者只写 review、不直接改作者稿；发现缺陷按具体段落、缺失问题/错误断言、依据和目标返还原作者。作者取得所有权后只修这些缺陷，补必要事实，不重启全仓调研；修后重新冻结、停止编辑。稿变使旧质量通过失效，即使改动发生在审核结束后也必须按影响范围复核。复核列最终实际身份、改动段、受影响上下游及沿用证据对应的旧版本，不能声称旧 hash 审过新稿。
4. 最终同一冻结版本独审通过，主会话才赋 validated、登记正式 delivered、更新索引和 POST-TURN。作者自查/V0、文章独审、源码核对、运行观察、用户能力分别记；两个 agent 不是实测或能力证据。

最终回复简短给真实文件产出、覆盖范围、正式/待独审状态和剩余缺口，不编完成百分比/ETA。准备、完整初稿、冻结待审、定点返修各阶段报告已有产物；耗时过长先缩无关旁支，保留必要解释深度。聊天答疑直接处理，实质缺漏返修受影响稿件，不让答疑等整课重编。

## 中断与写入故障

作者失败/超时/宿主限制时保存实际稿与未完成边界，不伪造完成。single 接手前结束原任务并明确交还所有权。恢复依靠源码、稿件/review 与 next_action，不依赖旧子会话；独审 waiting 不是继续教学的阻塞。待独审稿登记为 prepared，既可读也不能冒称正式 delivered 或掌握。

写入失败只更换可靠传输：用直接文件工具或 apply_patch，避免长 Windows 启动参数、含 Markdown 的 JavaScript 模板字符串及宿主不支持的编码 API。启动/传输失败未改文件，保留已写内容与分析，不重新备课；回读成功前不宣称已保存。中文分类与迁移见 [笔记协议](notes.md)。
