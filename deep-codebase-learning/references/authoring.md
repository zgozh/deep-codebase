# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还后才开始首次通读。优先宿主完成通知，需主动等待时选一种有界等待机制；同一任务无新状态时不交替 sleep、wait、list 重复确认。等待超时只表示本次未收到更新，不证明作者失败或空闲；遵守宿主等待时限和进度沟通要求，如实报告实际状态，不以固定等待次数截断必要编写或审读。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节因果目标；读真实源码及必要适用官方章节，先确定触发、准备、调用到返回的真实次序。从原始来源取得本课完整输入及关键转换；运行值未知时，用符合真实数据形状的完整假设对象并标明，展示局部投影也明确说明，不把熟悉的小例当完整输入。按此选定必需的真实行为单元，为每个单元确定路径、符号、原行、收到什么及交给谁，落实为唯一教材稿中实际5.x标题和八职责位置。delegated 由主会话将这些具体内容装入下述任务，single 自身作相同少量决策，不只转交“按模板详细写”。

### 源码写法输入

当前上下文第一次写源码精读，且尚未实际读过本版对应写法时，先实际读取 [quality-example.md 的完整5.3单元](quality-example.md#53-浏览器发起-get基类把解析结果交给项目的-do_get)：从5.3标题至5.4之前，包含八职责和源块后全部展开正文，作为写作样式输入。先导航，再只读这一个完整单元及当前确需前置，不合并倾倒整例、合同或模板；同版已读未变复用，不每节重读。纯全景/非源码课不强插，不另写样稿、汇报、考试或增加单元外审。

示范只展示怎样展开，不复制技术事实、行数或篇幅上限；真实语言/API按当前项目核实。继续按 [单一落稿任务](#单一落稿任务) 写完整课，其他九章与所有单元仍按原合同和基线，不能只模仿一处难点、长度或标题，也不能拿示范替本稿教学。阅读示范不代表本稿已通过，示例本身的实际核查与局限以页首说明为准。

### 单一落稿任务

开稿用 [宿主安全传输方式](#写入传输与局部恢复) 将已实例化的十章与选定单元骨架、一个完整实质小节同批保存到唯一draft稿，随后复用成功方式继续写；不另写空骨架稿、备课报告、矩阵或数据文件，也不增加批准。源码完整性按 [本课因果职责边界](teaching.md#第五章源码之前源码之中源码之后) 判断，不因同在一个方法而纳入其他独立职责；本课必要调用、输入、状态、当前失败与消费者仍须完整真实源码及逐句教学。跨出当前职责说明真实范围、接口影响和既有roadmap/coverage回收或接续；不能删当前难行、伪称已教，返修也不能静默缩小已承诺范围。

每个单元的完整源码、逐语义组充分正文及其余职责一起成稿，再进入下一单元；长单元仍可按连续源块连同紧邻正文分批保存，不逐行微写，也不先贴齐代码、留补深到末尾。综合回放放在原第四、七、八等章，不另造一个5.x吞掉真实单元的职责。非源码章按自身目标落实具体例子、因果与机制，不为落盘插源码。新发现必要依赖时只修受影响范围和接续点，不把初稿单元划分永久固定。尽早成稿不要求一次传输全文；写入失败先修传输并保留已写内容，按下述局部恢复继续，不删正文重启。已有稿返修仍按保留合同，正确必要概念、例子和解释不能静默删掉或迁往未写位置。

作者自主安排内部写作顺序，最终对读者仍按十章由总到细展示，全部适用小节与展开基线不变。必要前置在依赖处教清，第三章集中深入、第六章继续机制深化；非源码课沿原范围适配。

尽早写完整节厚稿，通常一次内容审读先看 [用户交付下限与扩写要求](teaching.md#用户指定的完整课交付下限)，再看每章关键事实、显著解释缺口及可读性，集中一轮定点修并按影响范围复读；不逐单元移交，不以每词/API穷尽或无限预读、复审阻塞交稿。仅下述形态校准适用时前移一个真实核心单元的审读，终审复用有效证据并覆盖全稿，不新增文件或备课矩阵。概念先短释再深入教，第六章不接收延期前置。必要资料缺口随写随查，读有用的官方规则并随受影响单元解释，不留到课后补资料清单；不等全仓精读，不另造资料汇编、过程文档或审查稿，不能凭缓存猜源码。

下面是唯一作者任务与落稿骨架，不再同时写一份brief。delegated 由主会话填好真实来源、完整输入、因果次序及实际5.x后交给作者；single 在同一稿首批实例化。括号换成实际内容，不泛化转发占位。实际5.x及源码形状仅用于本课确含源码精读时；纯全景/非源码课按原合同范围适配，不强造代码或单元。十章与适用单元位置先明确，同批写一个实质小节，未写部分仍 draft，不另交空骨架稿。

骨架仅给必需输出形状，不替代 [教材模板](../assets/templates/stage-note.md) 的全部章内小节，也不是篇幅上限。起稿先为 [完整课交付下限](teaching.md#用户指定的完整课交付下限) 与既有小节/语义组基线留足正文预算；充分旧文保留，极窄例外不能作整课缩短捷径。写到当前章/单元时分段读取其实际小节与必要合同段，不合读长合同、整份模板和review倾倒，不复制数字表或增加逐节计数步骤。

同版本规范、模板与证据在当前上下文已实际读过且未变才复用，丢失或变化时按需恢复。先用章节/符号导航，再读当前必需连续段，源码与紧邻正文同读；不把长规范、模板和整例一次合并倾倒，不重复全仓搜索。已识别源目录或符号后，rg 明确限定相关文件或实际源根；日志、备份教材仅确需运行或历史证据时单独纳入，不按目录名一刀切忽略，也不重新扫全仓。整个工具调用（含外层封装）的可见输出才算已读，被截断的当前必需段须定点补读；发出命令、rg 标题或过滤代码都不能代替正文，不反复倾倒整文件或整篇 diff。源码保留检查只证明保留，未改不等于已核真实；首次核当前源段及边界，有效证据才可复用，不另加核对轮次或表。作者先定 frontmatter 等元数据，交还时与正文一并冻结，审读期间不并行改同稿；终审核已吸收 brief 版本及最新反馈。中途变化只重开受影响内容，不重启整课；有价值变化及时留 checkpoint。

### 重大形态反馈后的首单元校准

依据当前已知最新反馈与教材实际表现，同类写法出现浅概述、重复铺解释等重大形态失败，或明确要尝试并校准新写法时，仅本课原已包含源码精读才将校准前移到同一稿首个真实、完整且有代表性的核心行为单元；纯全景或非源码课沿原章节目标补缺，不为校准插入新源码目标。不按作者身份、模型、版本、用户或新会话触发，不另查写作历史或维护作者档案。按既有教学合同与模板审实际正文，含当前必要问题、上下游、完整源码及全部八职责，不另写玩具短例或样例稿，不重搜无关资料或反复预读。单元确实过大则按原有因果完整性规则拆课，不能为轻快缩成摘要。熟悉且无此类失败的写法沿用常规完整稿一次审读，不把校准变成每课、每版本或每单元门禁；同一写作任务因同类反馈仅前移校准一次，后续必要修复按既有局部返修，不重启首单元仪式。

single 在同次写作中自查该单元，不另询问或等待用户，也不称独立审查。仅用户已选 delegated 时，作者可冻结同稿首单元及相关元数据范围，一次有界交还给原 Principal 实际校准；作者停写，Principal 交还所有权后再继续，不新增角色或子agent。发现形态问题先补好这个真实单元，将具体修正写法应用后文，不逐单元往返；缺口及实际边界沿用现有review短记和中断记忆，不另写长报告或每语句矩阵。一次局部通过不证明写法稳定或其他章/单元合格；不删减源码、概念、后置解释或任何展开下限。冻结范围后来被修改时，受影响证据失效并按影响链复读，未变且有效的证据保留。

### 全稿内容审读

通常完整稿做一次内容审读：single 作者自查，delegated 主会话自身独立读稿。若已作上述首单元校准，终审复用已核未变范围，实际审其余章节/单元及受影响衔接，累计覆盖全稿，不重复审核有效范围。同一次语义阅读实际覆盖 [十章表](teaching.md#唯一教学交付合同) 与 [章内展开模板](../assets/templates/stage-note.md) 中每章实际小节的全部适用职责，以及 [源码单元合同](teaching.md#第五章源码之前源码之中源码之后) 的每个行为单元八项固定职责。按模板入口的内容优先原则核合并/回指/不适用的真实依据和保留位置，当前必需含义、机制和具体值须已落实，否则仍 draft；不因小节名或一句章节职责通过，不为每小节另起审查记录。确认单元按初始化和用户动作的因果次序组织，有自己的问题/输入准备，完整必要源码及所有行的正文推导，并在本单元教局部运行、重要失败、机制与接入；不以第六至八章补缺。少数难点成功、全链正确或代表性证据不能代替其余单元的核查。所有章从初学者出发核概念、示范、推导、实值例子、定位和可读性，并核能否据真实约束作开发与架构判断；第九章答案有推导/回指，第十章有未知/下一课/能力边界。真不适用说明具体原因，不虚构。

这一次通读用下面两种判断核事实与教学，不另开审查轮次；single 自查也暂放写作意图。先不看作者自评或维护者答案，事实从原始来源和源码推演，教学再只凭正文重建，不让自己的知识替正文补解释：

```text
审读[冻结稿路径、实际章节/单元范围]；学习者此前只学过[真实已教内容及深度]，尚未教[当前必需概念]。
事实判断：先独立从[原始完整输入/值来源]及[真实源码路径、版本和范围]推演正常与必要失败条件，不沿教材叙事猜结果。核原始输入成员、初始化/默认来源及后续覆盖、关键转换、分支是否可达，再追实际生产、注册、转交/适配到状态及返回消费者；必要来源未读留未核，只查相关直接依赖与适用官方规则。将推演结果对照正文源块、调用、状态、图箭头及跨章重述，含第八章改法和第九章答案，核同一表达式、变量、顺序与定位。原注释、空行、连续范围及真实开闭亦按合同核，不把重排清理后的代码叫完整原文；改写/别名标教学示意。正文自洽不能代替来源支持。
教学判断：暂放自己的源码知识，仅凭教材沿同一完整输入复演每个有意义语句：怎样读表达式、名字/对象从何来、实参怎样绑定、产出由什么动作消费、何时改变状态或失败停止。跨相邻源块保持作用域和值，区分构造/返回与raise、执行、提交或写出及调用自身副作用；当前对象/输入、规则、输出/生命周期/失败和机制判断都须有正文依据，新概念在依赖前教。哪步靠经验补出就定位缺漏，正确综述不等于逐句教学。一组难点、短方法或“已教过”不能整段豁免；共享机制须定位充分前置及本次值/差异，类名或概念章链接不足。继续复演真实用法、架构交接及失败，核总述与逐组正文是否重复。
```

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。已跟踪稿用 Git 差异；ignored/untracked 的已有稿与该可恢复版本比较，例如 `git diff --no-index` 返回1表示内容有差异，超过1才查实际错误。空仓库 diff 不算原稿保留证据，不为比较 git add 或改 ignore；新稿直接读实际内容，不造旧稿。补缺须重组受影响单元，让问题、输入、源码、推导、演算、机制和接入各在对应小节，不只追加散段。按 [内容保留合同](teaching.md#返修保留教学内容) 核实际差异及影响段，保留有效源码、准确注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或去实质重复给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿说清边界，不为提速缩深度或用摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改/迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵/hash 报告。同一次冻结审读按行为单元核全部适用职责，当前实际审读范围结束后，将已知事实与教学缺口汇成一次有边界的返修任务，给同一作者具体位置、缺失推理及正确必要内容的保留要求；不先退几个错，再把同轮已见漏项另轮下达。当前冻结范围可一起处理的单句、链接及规则说明一并收尾，不逐项唤醒作者；读冻结稿期间不穿插作者编辑。若结构性问题已阻断余下审读，明确已读和未读范围后交回，不冒称全篇通过；重大问题和有价值 checkpoint 及时报告，不为汇总拖延。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的审读及 V0 证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。作者交稿后主会话复读相应范围，集中修复明显事实错、源码解释缺口及返修引入的问题，不为每词/API极致完善反复重开；必要范围未读或解释未补齐仍 draft，局部复读不补成全篇结论。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者实际失败或任务被宿主终止时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；一次等待超时不触发接管，恢复不依赖旧子会话。

### 写入传输与局部恢复

首次写入或返修前实际读取 [写入约定](writing-io.md) 的当前必要正文；发生写入故障时按其分类恢复，已读未变内容复用。规则与唯一传输示例已迁至该小页，无需为写入加载整个作者流程。
