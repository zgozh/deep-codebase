# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节问题与主链；读真实源码及必要适用官方章节，尽早写一份完整可读稿，具体缺口随写随查。不等全仓精读，不另造资料汇编或审查稿。未变已读 Skill/模板/资料复用，新会话、上下文丢失或文件变更才重读必要部分；不能凭缓存猜源码。

完整稿实际从头通读一次：single 由作者自查，delegated 由主会话自身独立读子稿，不只听作者报告。检查最终落盘文章首尾与展示内容，防止补丁标记、编辑指令或过期交接文字混入正文。顺着场景看读者能否理解每个重要表达式、概念与机制，同时代入具体正常/重要失败值核对源码、状态与返回消费者；解释应紧邻，不能是术语/链接墙。能走值链不代表语法/机制已讲；审核者自己懂不补正文。发现具体缺口先补教材，“读过全文”不能推翻实际漏讲，也不用把路径答案再抄成一套报告。

按 [笔记协议](notes.md#note-quality-gate) 简记真实方法、范围、关键缺陷/处理及未核实项。single 合格稿记 ready/self_review，delegated 经主会话真实独立审读的范围可记 validated；二者都可正式 delivered，不代表实测或用户能力。做必要 V0：UTF-8 回读、围栏配对、本地链接/索引、相关 JSON 与状态指针，核相关源码原行/内容和版本；没有应用改动只做文档检查，不跑应用测试/构建/浏览器。有效未变证据不重复，最后只改状态指针就只补相关检查。保存索引和本轮实际学习变化后，简短给主题、覆盖范围与笔记链接；答疑直接充分回答。

## 返修保留教学内容

先确认一份可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。按 [内容保留合同](teaching.md#返修保留教学内容) 局部修缺陷，保留正确必要解释，并复读改动及上下游、对照是否丢教学单元。删错/重复给具体依据；迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿则说清保留核对边界，不把摘要当完整返修。需要多解释时写足，收无关旁支不收深度。

仅广泛重写、源码范围大变或影响不明才全文重读；局部改字/状态收尾不使所有结论自动失效。简记实际复核范围，不逐段复制证据表，不为每次返修新造报告。delegated 返还同一作者具体位置/依据/目标，作者交稿后主会话复读影响链；必要解释未补齐仍 draft，不能为交付好看编通过。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者失败/超时时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；恢复不依赖旧子会话。

Windows 中文显式 UTF-8，Python 检查用 `-X utf8`。补丁匹配失败刷新实际局部，换唯一短锚点或安全局部替换；传输/编码失败先换可靠文件工具/apply_patch，不原样重试长命令、不重新研究全项目。回读成功前不声称已保存，依赖保存的跨 Topic 推进仍须等待保存成功。
