# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还冻结范围后，主会话才开始独立审读。优先宿主完成通知，需主动等待时选一种有界等待机制；同一任务无新状态时不交替 sleep、wait、list 重复确认。等待超时只表示本次未收到更新，不证明作者失败或空闲；遵守宿主等待时限和进度沟通要求，如实报告实际状态，不以固定等待次数截断必要编写或审读。

## 写出、读懂并交付一节

先按 [交付类型入口](../SKILL.md#开始或继续) 判断正式教材或即时答疑；局部/单函数正式源码笔记仍进入本流程、唯一教材模板及正常Note Quality审读，不因范围窄跳过既有review。review是学习产品已有质量记录，不是另造评测报告；不把禁止新增评测报告自行扩大为免除正常学习记录，宿主真实权限限制仍须遵守并准确说明未完成项。

首篇正文前先按[记忆协议](memory.md#schema-v1)建立最低state和当前Stage，已有记录恢复而不重置。恢复最新偏好、教材边界及源码身份，按真实生命周期/结果边界选少量内聚问题：每个有具体输入、可观察结果/状态和真实消费者；记录贯穿主体/生命周期、关键值及A/B条件变化，不把返回、回放、机制或下一课导航另编5.x，不固定项目单元数。初稿只读足以建立主线的项目来源；扩写到当前单元再读决定分组所需源码，确定触发、准备、调用到返回的真实次序。适用官方规则在正文解释遇到时按需实际核读并讲入推导，不先研究全课框架。从原始来源取得本课完整输入及关键转换；运行值未知时，用符合真实数据形状的完整假设对象并标明，展示局部投影也明确说明，不把熟悉的小例当完整输入。选单元时沿具体值或函数找到实际产生/创建、登记/适配、调用/回调及消费表达式：决定本课对象、类型、状态或控制结论的最小完整实现必须进入源码教学，只给依赖路径和用途不算完成；真正只需接口的旁支仍交代边界与接续，不追整套框架。按此选定必需的真实行为单元，为每个单元确定路径、符号、原行、收到什么及交给谁，落实为唯一教材稿中以真实符号/行为命名的5.x及其下八职责位置。不同因果问题的独立行为分别成单元，紧密合作的内聚职责可同单元，不机械一函数一单元，也不把整课5.1–5.8当作共用八职责。delegated 由主会话将这些具体内容装入下述任务，single 自身作相同少量决策，不只转交“按模板详细写”。

### 源码写法输入

当前上下文第一次写源码精读，且尚未实际读过本版对应写法时，先实际读取[完整源码单元示范](source-unit-example.md)，包含七个写作位置/八职责及全部源码后展开正文，作为写作样式输入；连续读取这个完整单元，不用head+tail跳过中间的代码后正文。同版已读未变复用，不每节重读，也不强制同时读两例；[旧完整功能示例](quality-example.md)保留，整课排版需要时按需参考。只读当前确需前置，不合并倾倒整例、合同或模板；纯全景/非源码课不强插，不另写样稿、汇报、考试或增加单元外审。

凡开始实际5.x写作，包括局部/开发校准，都先从canonical读取或复用[当前原行组的段落任务](../assets/templates/stage-note.md#当前原行组的段落任务)，不依赖先经过整课draft/expand，也不让局部校准强跑整课；新写/整体厚写源码单元按该处在同一raw先实际保存最终分组布局，再回读并连续填正文，不新增计划文件或审批。仍须读取或复用[canonical完整单元骨架](../assets/templates/stage-note.md#5x-真实符号本单元具体行为)，直接实例化其七个H4写作位置；职责名固定，可加本课语境，不能替成“定位/释义/输入/源码前/源码后/状态/失败/衔接”八项。委派传该骨架原文必要片段，母会话不另造目录；正文仍一次充分写足。源码精读还须按稳定标题实际加载当前必要的 [源码之中](teaching.md#源码之中完整真实职责与教学注释)、[源码之后](teaching.md#源码之后逐行理解再运行与判断) 及 [执行机制与数据](teaching.md#执行机制与数据要讲到哪里) 范围；不能只读合同前半或预算表就转入官方资料。它们与当前模板共同作为落笔输入，同版已完整读过且未变才复用，不重读全套。

示范只展示怎样展开，不复制技术事实、行数或篇幅上限；真实语言/API按当前项目核实。继续按 [单一落稿任务](#单一落稿任务) 写完整课，其他九章与所有单元仍按原合同和基线，不能只模仿一处难点、长度或标题，也不能拿示范替本稿教学。阅读示范不代表本稿已通过，示例本身的实际核查与局限以页首说明为准。

### 单一落稿任务

普通一次“学习/继续”请求的完整交付边界是本课充分扩写、累计审读和集中收尾。同一课ID/唯一最终note依次使用 [draft：完整初稿](draft-lesson.md) → [expand：当前章/内聚单元充分扩写](expand-lesson.md) → [finalize：累计审读与集中收尾](finalize-lesson.md)；完整正文先持久保存为当前章/内聚源码单元的UTF-8 part，装配时从raw自动渲染源码生成新candidate，审读后纯字节发布。single在同一会话自动接续，不是三个新的用户任务、额外模型调用或逐章审批；已有draft恢复后继续本次已授权展开，不等用户再次说继续。

draft/prepared和next_action checkpoint只表示真实中间边界，不是推迟本次展开的许可。只有用户明确暂停、必要授权/源信息缺失，或真实宿主容量/权限/工具无法恢复等实在阻碍，才可本次以draft结束，并记实际原因、已保存范围和返回点；任务大、当前字数不足、已保存next_action都不是理由。正常分章厚写属于本次编写，不是返修或开发试写失败；开发trial重复同类失败的冻结规则不变，不变成运行时按次数弃任务。

每阶段只读当前入口及当前章所需模板/合同/源码/官方段；已读未变证据复用，不为阶段推进重读全部长规范。教学职责与深度仍只由 [teaching](teaching.md#唯一教学交付合同)、[唯一教材模板](../assets/templates/stage-note.md) 及 [SKILL整课下限](../SKILL.md#整课交付硬约束) 定义。三入口只组织执行，不复制合同或数字表，也不降低原源码、解释或各章篇幅要求。

阶段内自动推进到完整课交付；章组织整条业务链，5.x按真实生命周期/结果边界选内聚问题，不机械每helper建七节，也不把整条链自动塞进一个大5.1。expand自动复用[短章请求框架](../assets/templates/chapter-request.md)与canonical模板，在当前落笔的真实原行组里找尚未解释的表达式，承接前组具体值并立即写其读法、求值/绑定、触发和消费者，必要机制/判断紧随其后，再接下一组，连续写足本单元。各组/概念/源前后原预算照旧，不以整块用途或尾章问答代替。已有review及充分前文直接复用，不另抄任务卡；Stage仅保原有一句文件/返回点，不逐组审批或同步共享记录，不为分组机械新增模型/工具调用；当前必要源码/官方资料仍按需读取，容量所需保存仍允许。single保存叙事和source include的raw part，用户已选宿主子作者写独占part；代表性单元可[预览校准](writing-io.md#渲染当前part)，正式装配直接读raw自动渲染，审读后原字节发布同一独立note。真实有价值互动/中断及时最小保存，其余记录集中收尾；写作数据不是已教或掌握。

### 首个完整扩写单元的就地校准

执行位置见 [expand](expand-lesson.md)：完整初稿后，本稿首个真实代表性完整源码单元的既有写入/回读先实读全部七位置及源码组、观测实际相邻正文范围，再继续其余。先核真实API签名、类型/输入输出、返回与被忽略返回、登记副作用及后续Lookup/消费者，区分注册/解析/回调、生成器/模板/生成应用等阶段；同值不等于同一对象或一次读取，snapshot不冒充再次Get。只查当前必要定义/适用官方规则，并把白话、具体值和机制/工程判断写进正文，不追整套框架。复用本稿已核未变证据，首次不因熟悉自免；single自查不等批准、不称独审，不另加一轮或样稿。已选delegated时可冻结该真实范围交原Principal一次有界校准，作者停写，所有权交回后继续；不新增角色或逐单元往返。纯非源码课不为校准插入源码目标。

### 全稿内容审读

执行位置见 [finalize](finalize-lesson.md)：扩写中累计一次事实/教学审读，收尾补未核范围及跨章衔接，按 [review](../assets/templates/review.md#教材通读与修订note-quality) 留真实每章/单元短依据；single自审与delegated独审分清。全部适用范围仍实际覆盖，不能由一处难点、标题或数量推定全稿通过。必要缺口成批定点修，只复读影响链，未变有效证据保留；任一必要未核/未补整课仍draft。无新错不重读全书，不为非必要深挖与措辞反复重开。

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。已跟踪稿用 Git 差异；ignored/untracked 的已有稿与该可恢复版本比较，例如 `git diff --no-index` 返回1表示内容有差异，超过1才查实际错误。空仓库 diff 不算原稿保留证据，不为比较 git add 或改 ignore；新稿直接读实际内容，不造旧稿。补缺须重组受影响单元，让问题、输入、源码、推导、演算、机制和接入各在对应小节，不只追加散段。按 [内容保留合同](teaching.md#返修保留教学内容) 核实际差异及影响段，保留有效源码、准确注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或去实质重复给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿说清边界，不为提速缩深度或用摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改/迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵/hash 报告。同一次冻结审读按行为单元核全部适用职责，当前实际审读范围结束后，将已知事实与教学缺口汇成一次有边界的返修任务，给同一作者具体位置、缺失推理及正确必要内容的保留要求；不先退几个错，再把同轮已见漏项另轮下达。当前冻结范围可一起处理的单句、链接及规则说明一并收尾，不逐项唤醒作者；读冻结稿期间不穿插作者编辑。若结构性问题已阻断余下审读，明确已读和未读范围后交回，不冒称全篇通过；重大问题和有价值 checkpoint 及时报告，不为汇总拖延。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的审读及 V0 证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。作者交稿后主会话复读相应范围，集中修复明显事实错、源码解释缺口及返修引入的问题，不为每词/API极致完善反复重开；必要范围未读或解释未补齐仍 draft，局部复读不补成全篇结论。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者实际失败或任务被宿主终止时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；一次等待超时不触发接管，恢复不依赖旧子会话。

### 写入传输与局部恢复

首次写入或返修前实际读取 [写入约定](writing-io.md) 的当前必要正文；发生写入故障时按其分类恢复，已读未变内容复用。默认source include、渲染与安全原文保存路径在该小页，无需为写入加载整个作者流程。
