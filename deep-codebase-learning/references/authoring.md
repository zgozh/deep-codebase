# 单会话与可选委派编写

## 首次选择与所有权

默认 single：当前模型规划、写教材、实际通读与保存，完整合格教材可以正常 delivered。首次在学习项目使用时简短询问一次：“采用单会话编写，还是主会话规划审查、子 agent 编写教材？”使用可用文本选择工具，无工具则在首次交付回复询问；无答复仍 single，沉默不授权委派。已有明确选择沿用，存当前 stage/journal，切阶段继承，不新增必填 state 字段。

delegated 需要宿主支持且用户选择，可能增加耗时/资源，不保证更好。Skill 不固定模型/推理档位，不要求安装服务、MCP、CLI 或后台。主会话拥有路线、最新偏好、索引与共享学习状态；子作者只拥有指定一节稿件，不改 state/journal/mastery/coverage/其他稿或项目代码，不提交/部署/安装或做未授权实验。任务给稳定 ID、唯一中文稿路径、具体场景/目标、前课真实解释深度、必要源码/官方资料、起止符号、排除旁支和接续点，遵守 [教学合同](teaching.md#唯一教学交付合同)。同稿只一人写，移交后再编辑；默认一次一节，独立并行也须明确所有权/依赖。作者停止写稿并交还后才开始首次通读。优先宿主完成通知，需主动等待时选一种有界等待机制；同一任务无新状态时不交替 sleep、wait、list 重复确认。等待超时只表示本次未收到更新，不证明作者失败或空闲；遵守宿主等待时限和进度沟通要求，如实报告实际状态，不以固定等待次数截断必要编写或审读。

## 写出、读懂并交付一节

恢复最新偏好、实际教材边界及源码身份，选择本节问题与主链；读真实源码及必要适用官方章节，将本节问题、真实符号和输入在下述既有 brief 中绑定到 [十章教材骨架](../assets/templates/stage-note.md) 的实际小节任务，委派也不能只说“遵守 Skill，详细写”。

开稿就用 [宿主安全传输方式](#写入传输与局部恢复) 将本来要写的第一个完整实质小节保存到唯一稿件，随后复用已成功的方式，按连续章节或内聚行为单元继续写出。写作单元与保存单元一致：一段完整职责或连续源块连同对应逐语义组充分正文同批落盘，再进入下一块/单元；非源码章仍按本章目标落实具体例子、因果与机制，不为落盘插入源码。不是逐行微写、额外试写或另建文件，也不能先贴齐全部代码、给全章各填几句概述占位，再把补深留到末尾。尽早形成完整可读稿指最终教学完整，不是一次传输整课；不要先在巨型请求中积攒全文。一次写入失败先修传输并保留已写内容，按下述局部恢复继续，不删正文重启整稿。

内部写作顺序不改变读者的十章次序；通常完整稿一次内容审读，不逐单元移交。仅下述形态校准适用时前移一个真实核心单元的审读，终审复用有效证据并覆盖全稿，不新增文件或备课矩阵。首次完整课或重大反馈时按正在写的章节读 [小型完整功能读码示例](quality-example.md) 的相关写法，确需整体对照才读整例；已读未变内容复用。它不是大型全栈代表课或真实课尺寸上限，历史 helper 只供局部语法校准。示例的语言、版本和业务事实按真实技术栈核实；概念先短释再深入教，第六章深化机制，不接收延期前置。必要资料缺口随写随查，读有用的官方规则并随受影响单元解释，不留到课后补资料清单；不等全仓精读，不另造资料汇编、过程文档或审查稿，不能凭缓存猜源码。

开写前在已有当前 stage、稿件开头或委派任务放四行 brief，不另建备课文件：

写作与下述一次通读共用 [试行扩写基线](teaching.md#试行扩写基线重要小节要展开到什么程度)：每个重要小节和首次解释的语义组厚写实际因果，不先铺几句占位。下面作者任务与冷读任务均携带此引用，不复制数字表，也不新增计数步骤。

- 本节完整因果目标、为什么现在讲、真实源码路径/版本与起止符号；本轮采用的 Skill 版本。
- 必追的具体输入值、调用者、直接被调方法、中间转交/适配表达式与结果消费者；开写即按真实来源、过滤、分支及输出契约推通本节一组正常值和必要失败值，重要能力包含合法正例，不只用违规输出展示功能；读生产和接线确认起止交接、可达性、时机及状态副作用，演算留在本 brief/正文并复用同组值，不另做演算文件。
- 已经实际教到的前置深度及教材段落/聊天事件出处，当前未教但必需的概念模型与适用版本规则；明确本次操作所需的表示、单位或状态含义，不把名称或演算当作模型已教。
- 当前真正难懂的机制及将用来讲清的真实代码、具体值与必要示意，无相关难机制不硬造；有实际重要延期时说明内部的接口/当前影响、Future Topics 中的回收节点与返回点，已有节点复用，无延期不为填 brief 造条目；最新反馈事件与对本稿的具体影响。

同版本规范、模板与证据在当前上下文只读一次，丢失或变化才按需恢复；只读主链和必要直接依赖，不重复全仓搜索。用稳定章节/符号定位，按输出预算读取能完整展示的连续范围，源码与紧邻正文同读；标题筛选只作导航，过滤代码不能证明逐块已核。输出截断的缺失范围仍未读，从最近成功位置续读缺失段，不反复倾倒整文件或整篇 diff。源码块保留检查只证明保留，未改或沿用不等于已核真实；首次核当前范围的源码内容与边界，有有效证据后才复用，不另加核对轮次或表。作者先定 frontmatter 等元数据，交还时一并冻结正文与元数据，审读期间不并行改同稿；冻结与终审都核最终稿已吸收 brief 所列版本要求和最新反馈。中途规范或反馈变化只重开受影响内容，不重启整课。通信和等待沿用上述约定，有价值的实际变化及时留 checkpoint。

可把这四行直接展开成作者任务，single 也可作为自己的开稿任务；用实际内容替换括号，不另建任务表：

```text
只编写[唯一稿路径]的[本节/单元范围]，目标是让初学者解释[真实动作如何产生结果]；现在讲是因为[当前功能与前置依赖]，按完整因果目标而非文件或固定方法数划界。
源码为[路径、版本、原行/起止符号]；开写即以[正常具体输入及必要失败值]沿真实来源、过滤、分支及输出契约推通[生产者/调用者→创建或注册→实际转交/适配表达式→状态/返回消费者]，重要能力含合法正例，不只示范违规输出。演算在本任务/正文复用同组值，不另建文件；实际路径算通再解释，不以省时删教学。按teaching.md“执行机制与数据要讲到哪里”，把正文关键值断言追到真实初始化/赋值来源及本次消费者；只查必要直接范围，证据缺留未知，参数简写另标教学示意。
此前实际已教[内容、深度及教材段落/聊天事件出处]；尚未教[当前必需概念模型]，按teaching.md的初学者前置要求，在首次依赖处讲清当前对象/输入、规则及输出/生命周期/失败，再演算本次值；说明中必需的新概念先补，不用陌生词解释陌生词。
采用[Skill版本]及[最新反馈的具体影响]。按职责连续写完整源块及紧邻语义正文；分块保持真实原行和未闭合作用域，短说边界及后块如何继续，不补造闭合或返回。讲读法、带值执行、机制与修改后果；区分表达式产出的对象/返回值与消费它的raise、执行、提交或写出动作，并读直接实现确认调用自身的副作用、真实时机和失败路径。声明支持而当前无生产路径的分支如实区分。
当前难机制是[实际现象及真实代码/具体值/必要示意，无则不硬造]。沿已有八职责从定位进入完整职责实现与逐行推演，再以同一输入回到真实调用、上下游、接入及取舍。本节止于[结果及后续消费者]；仅有实际重要延期时说明[内部机制、接口与当前影响]及Future Topics的[回收Stage/节点与返回符号/问题]，已有节点复用，无延期不造条目。资料限[必要源码与适用官方章节]。
按teaching.md的“试行扩写基线”展开当前小节与首次语义组；每段用本次表达式、值或条件发展新解释。工程判断给具体可行替代，用同组正常值及重要失败条件比较调用次序与已发生副作用，成功返回相同不等于行为等价，必要解释就地展开；接入用一个实际改动追接线和漏接表现。源码量、标题和重复结论不能抵正文。缺教学先补，低于默认量但已充分承担实际职责的正文给精确位置及具体依据，不为凑字重写或压缩，不把未来课当已教。
冻结正文与元数据后交还；只报告实际范围和未解项，不以作者自评代替审读，不改共享状态或其他稿。
```

重大深度反馈或需要辨别“概述还是教学”时，按正在写的内容读 [源码单元校准](teaching-calibration.md) 中的对应对照，包括连续源码与紧邻正文、非源码章的因果展开；不强制全量预读，不每课加载，也不把其语言、源码规模或局部写法当成整课要求或通过结论。

### 重大形态反馈后的首单元校准

依据当前已知最新反馈与教材实际表现，同类写法出现浅概述、重复铺解释等重大形态失败，或明确要尝试并校准新写法时，仅本课原已包含源码精读才将校准前移到同一稿首个真实、完整且有代表性的核心行为单元；纯全景或非源码课沿原章节目标补缺，不为校准插入新源码目标。不按作者身份、模型、版本、用户或新会话触发，不另查写作历史或维护作者档案。按既有教学合同与模板审实际正文，含当前必要问题、上下游、完整源码及全部八职责，不另写玩具短例或样例稿，不重搜无关资料或反复预读。单元确实过大则按原有因果完整性规则拆课，不能为轻快缩成摘要。熟悉且无此类失败的写法沿用常规完整稿一次审读，不把校准变成每课、每版本或每单元门禁；同一写作任务因同类反馈仅前移校准一次，后续必要修复按既有局部返修，不重启首单元仪式。

single 在同次写作中自查该单元，不另询问或等待用户，也不称独立审查。仅用户已选 delegated 时，作者可冻结同稿首单元及相关元数据范围，一次有界交还给原 Principal 实际校准；作者停写，Principal 交还所有权后再继续，不新增角色或子agent。发现形态问题先补好这个真实单元，将具体修正写法应用后文，不逐单元往返；缺口及实际边界沿用现有review短记和中断记忆，不另写长报告或每语句矩阵。一次局部通过不证明写法稳定或其他章/单元合格；不删减源码、概念、后置解释或任何展开下限。冻结范围后来被修改时，受影响证据失效并按影响链复读，未变且有效的证据保留。

### 全稿内容审读

通常完整稿做一次内容审读：single 作者自查，delegated 主会话自身独立读稿。若已作上述首单元校准，终审复用已核未变范围，实际审其余章节/单元及受影响衔接，累计覆盖全稿，不重复审核有效范围。同一次语义阅读实际覆盖 [十章表](teaching.md#唯一教学交付合同) 与 [章内展开模板](../assets/templates/stage-note.md) 中每章实际小节的全部适用职责，以及 [源码单元合同](teaching.md#第五章源码之前源码之中源码之后) 的每个行为单元八项固定职责。按模板入口的内容优先原则核合并/回指/不适用的真实依据和保留位置，当前必需含义、机制和具体值须已落实，否则仍 draft；不因小节名或一句章节职责通过，不为每小节另起审查记录。确认单元按初始化和用户动作的因果次序组织，有自己的问题/输入准备，完整必要源码及所有行的正文推导，并在本单元教局部运行、重要失败、机制与接入；不以第六至八章补缺。少数难点成功、全链正确或代表性证据不能代替其余单元的核查。所有章从初学者出发核概念、示范、推导、实值例子、定位和可读性，并核能否据真实约束作开发与架构判断；第九章答案有推导/回指，第十章有未知/下一课/能力边界。真不适用说明具体原因，不虚构。

这一次通读可直接采用以下冷读任务；single 自查也先暂放自己的写作意图，从正文重建。先不看作者自评或维护者答案，不让它们替正文补解释：

```text
审读[冻结稿路径、实际章节/单元范围]；学习者此前只学过[真实已教内容及深度]，尚未教[当前必需概念]。
沿求值/行为边界逐块读源码与紧邻正文，先只凭正文复演[具体输入]：表达式怎样读、名字/对象从何来、实参怎样绑定、调用产出什么、由什么动作消费、何时改变状态或失败停止。跨相邻源块沿同一作用域和值继续，核初学者能否据正文说明当前对象/输入到规则再到输出、生命周期或失败，必需新概念是否先教，而非只有名称或算式。区分构造/返回与raise、执行、提交或写出，也核调用本身的副作用；哪步靠了你自己的经验，回找正文依据，找不到就定位缺漏。
再对照[真实源码路径/版本/原行]及必要直接依赖与已读官方规则，逐块核连续原段、真实开闭位置、调用时机与副作用。按同一来源核查要求，将关键值、为空及默认行为的断言追到真实声明/初始化与后续覆盖，再到当前消费者；正文自洽不等于源码支持，必要来源未读则留未核，不重扫全仓或另做整篇审查。追实际生产、注册、转交/适配到消费者表达式，分别判断声明分支与当前可达路径；共同机制要能映射回当前语句和值，未核处留未知。
先从正文找解释证据再分别判断事实正确与教学充分；当前主行为每个不同求值、分支、赋值及返回动作均须能从紧邻正文恢复，正确综述仍不等于逐句教学。一组难点正确不推成全单元通过；“已教过”“短方法”或默认知识不能整段豁免。共享机制或短段例外在既有review具体定位充分前置及当前应用，类名或概念章链接本身不足。缺口指出实际表达式、缺失推导和应修正文位置。继续复演真实使用、架构交接及重要失败，核总述与逐组正文是否重复；相同解释重复不抵展开下限。
结论只覆盖实际读过的范围；按现有review短记，不增加逐行表或另起报告。一个单元通过不代表十章整课通过。
在这同一次语义阅读中按teaching.md的“试行扩写基线”粗看展开量与新增教学点，核工程判断是否只复述流程，替代是否用同组正常值及重要失败条件比较调用次序与已发生副作用，而非由成功返回相同推定行为等价；核用法是否只列文件、语义组是否省了具体求值或机制。缺教学定位并退修；低于默认量但已充分承担实际职责的窄例外核精确正文位置及具体依据，共享机制核本次值/差异。事实与教学判断优先，达量不等于通过，不为凑字退修充分正文，不另开计数审查。
```

通读时积累核查结果，完成后一次写入现有 [review](../assets/templates/review.md)：十章各一条短普通列表，第五章另对实际每个5.x行为单元各一条，不逐语义组写盘、不另建文件。每条分别记事实与教学的已核/未核/待修或待补；每章一条内注明实际已核小节范围，用一处实际核过的表达式/值转换或具体因果关系及支持解释的正文位置，使记录可复查，并记剩余缺口。待修项指出实际表达式或论述、缺少解释及修复位置，未核明确到实际小节/范围。稳定章节/符号优先，必要时给准确局部行。这处短证据用于显露核查内容，不代表抽一处即证明全章；核查仍须覆盖每章各小节和每个行为单元全部适用职责，一条“全课通过”、少量清单、抽查与调用链正确均不能吞掉未核内容。不做每小节多维记录或每行×八职责的大矩阵，不重复抄教材/报告，不维护教材字节/hash 品质字段。任一必要范围未核或教学未补齐，整课仍 draft，局部通过不能整体升级；只抽查就限定结论。合格 single 记 ready/self_review，真实独审范围才可 validated。局部修复只复读影响链并更新相应短记录，复用未受影响证据。有限静态试用不替代用户明确验收，不证明应用、模型长期稳定或真实学习效果。

收尾一次完成必要文档 V0：UTF-8 安全回读、围栏及相关链接/索引/JSON/指针，复用未受影响的有效检查。回读最终展示首尾防止补丁/过期交接混入。明确跳过应用检查时不运行；无应用改动不跑应用测试/构建/浏览器。通过后由主会话集中更新一次必要索引/state/stage/journal，再简短交付主题、范围和入口；有价值问答及中断仍及时保存，不等整稿完成。

## 返修保留教学内容

先读现有稿件基线并确认可恢复修前版本：可靠 Git 历史足够，无则留一个本地快照，不无限备份。补缺须重组受影响单元，让问题、输入准备、源码、逐行推导、演算、机制和接入各在对应小节，不能只追加散段反复解释。按 [内容保留合同](teaching.md#返修保留教学内容) 读实际 diff，保留有效源码、准确教学注释、必要概念/例子/推导。格式检查不能证明内容保留；删错或实质重复给依据和保留去向，迁移须目标已写好、引用有效、本节必需含义仍在。无完整旧稿说清边界；不为提速缩深度或用自动摘要代教材。

在同一 review 短记具体缺口、修复位置及必要正文依据；实质删改/迁移说明原因与正确必要解释的已写好去向，不另建逐段矩阵/hash 报告。同一次冻结审读按行为单元核全部适用职责，当前实际审读范围结束后，将已知事实与教学缺口汇成一次有边界的返修任务，给同一作者具体位置、缺失推理及正确必要内容的保留要求；不先退几个错，再把同轮已见漏项另轮下达。当前冻结范围可一起处理的单句、链接及规则说明一并收尾，不逐项唤醒作者；读冻结稿期间不穿插作者编辑。若结构性问题已阻断余下审读，明确已读和未读范围后交回，不冒称全篇通过；重大问题和有价值 checkpoint 及时报告，不为汇总拖延。同稿修后按缺口及其依赖范围复读改动和上下游，复用未受影响的审读及 V0 证据；仅广泛重写、源码范围大变或影响不明才全文重读。不反复输出整篇 diff，不以缩字目标、KB 或章节数判断深度。作者交稿后主会话复读相应范围，后来发现的新缺口仍须修复，不设固定返修轮数；必要范围未读或解释未补齐仍 draft，局部复读不补成全篇结论。

## 中断、记忆与写入故障

每个有价值互动及时按 [记忆协议](memory.md#post-turn-learning-commit) 保存实际变化，讨论或中断留最小 checkpoint，不等整课成功才保存。唯一主会话维护共享状态和 pending 恢复，不复制整篇教材到记忆。作者实际失败或任务被宿主终止时如实保存现稿/未完边界，结束任务并交还所有权后可 single 接手；一次等待超时不触发接管，恢复不依赖旧子会话。

### 写入传输与局部恢复

Windows 中文显式 UTF-8，Python 检查用 `-X utf8`。复用本任务已成功的传输方式，主用宿主原生 patch 或普通字符串字面量，不为每次修改重新拼装变体。首次选择写入方式时可直接采用本节末尾的普通字符串补丁形状；经 JS/functions.exec 时不用 `String.raw` 或其他含 Markdown 反引号正文的模板字符串。按一个或几个相邻内聚单元成批补丁，相关缺口一次补齐其职责；用刚读到的稳定唯一短锚点及必要前后文，不按整页长旧段或漂移行号匹配，相关多处缺口不拆成逐句反复调用，独立新发现的单处错误可一次定点修；也不改成整篇重写或难定位失败的巨补丁。反复上下文失配时，可在已确认唯一的标题区间准确替换当前本地单元，保留边界与可恢复旧版并核实际diff；这是局部恢复选择，不要求所有项目整段替换，不新增脚本或工具。

故障先按实际返回分类：请求格式、JS转义、invalid hunk、NaN或解析失败，先核请求拼装及当前工具格式；经JS/functions.exec拼装时，diff的加减号和上下文前缀须在普通引号字符串内，不能写成一元数值转换，不通过调行号或盲读原稿修格式。直接apply_patch遵从宿主真实schema，无需给diff正文额外加字符串引号；优先直接调用宿主提供的apply_patch；经functions.exec传输时不用含Markdown反引号正文的JS模板字符串，不把大正文塞Windows启动参数。expected lines/context mismatch 才回读当前局部，取准确的短唯一锚点，不用旧 diff 行号或旧长段重试；输出截断按前述未读范围续读，不因此重写。

首次同类失败后，先完成当前本就需要的一个小修改，确认写入方式已恢复，再按完整内聚单元继续；不另建测试、探针、脚本或备课文件，不把所有修改拆成单句，不删缩正确教学。同一未解决的请求拼装/传输错误再现时，暂停该失败写入路径，不再调行号/原文或重复同一拼装；另一个局部新出现的expected lines失配仍按当前局部取唯一锚点规则处理。保留现稿与未完成范围，改用宿主已可用的可靠写入方式继续当前局部任务，确认真实变更及范围。没有可靠方式则如实报告未保存与阻塞，不虚称修好、不重启整课或擅自结束原任务，也不设教学返修轮数上限。工具误写只核这次diff并恢复无关触碰，不整篇回滚丢掉正确教学。格式错误明确未执行时不重收资料或重审教材；其他失败不一概假定无变更，按实际返回及必要局部回读确认。收尾集中写本次必要 projections，不为匹配失败重读整篇。必要源码与官方规则查证仍须完成，不能当作浪费删掉。按实际落盘阶段汇报，执行成功及必要回读未确认前不声称已写完或保存，依赖保存的跨 Topic 推进仍须等待保存成功。

仅当宿主提供functions.exec与tools.apply_patch时，可用下列传输形状；其他宿主遵从实际工具schema。它仅示传输，不是课程样例、额外脚本或每课探针；Markdown 反引号可直接放在普通引号字符串内。直接看拼装后的字符串即可判断各行前缀，不能把`+`/`-`放到引号外写成`+"文本"`/`-"文本"`，不另造运行前检查器。

~~~javascript
const patch = ["*** Begin Patch", "*** Update File: path/to/note.md", "@@", " 保留的上下文", "-旧正文", "+新正文中的 `名称`", "+```python", "+print(1)", "+```", "*** End Patch"].join("\n");
text(await tools.apply_patch(patch));
~~~
