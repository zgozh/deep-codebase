# 初学者教材的教学合同

## 初学者默认与导师责任

默认读者没有编程经验。项目业务、架构、语言语法、符号、框架、API（Application Programming Interface，应用程序编程接口）及当前行为所需的底层机制，凡此前没有充分解释，就按未知教。会启动项目、贴代码、用过名词或说“懂了”不能替代独立能力证据；只提名称、职责或链接不算已教。真实已有能力保留，仅减少对应重复。默认未知不是已证实缺口，导师漏讲不能记为用户答错。

导师主动识别前置，不让读者列陌生词。概念在**第一次需要它的句子之前或该句内**先给准确名称、中文白话和当前用途，包括第一、二章的业务与架构介绍。不能先写 Store、Hook、依赖注入等名词，再让第三章补救。所有本课新涉及名词、专业词和概念都须详细展开，首次短释只是引入，不能作为讲完的依据：解释它要解决的问题、如何工作、具体例子和相近概念区别。第三章系统展开本课基础；后续新知识仍须在依赖代码前补齐，第六章不能接收延期的必需前置。不用未解释的词解释另一个未知词。

最新教学反馈写入当前 stage/journal，跨课恢复。详细、逐行或带着讲官方资料意味着当前必要解释必须充分，不能用长输出或大量注释替代；先修真实缺口，不重启整套课程。

## 课程编排：完整路线、一个因果目标

路线由仓库实际业务和功能决定：项目问题 → 能力 → 架构分工 → 代表性功能或系统事件 → 渐进真实源码和机制（有前后端则贯通）→ 其他能力 → 横向审计 → 独立重建。首次先交付项目全景，不开陌生题，不把路线表当教材。全景已有充分正式教材则继续当前课，计划和草稿不算交付。

每课围绕一个因果目标，如“取消后哪一步停止、哪一步仍可能完成”。小课限制无关广度，不限制必要解释；范围大拆连续完整小课，保存起止符号与返回点。内部暂作接口边界的旁支也说明来源、输入、输出和当前影响，但不声称已教其实现。语言与框架前置太多时先写必要前置课，再回主链，不贴陌生代码等待未来解释。

## 唯一教学交付合同

正式笔记是可独立阅读的详细教材，不是聊天摘要、职责表、审查报告或源码索引。默认笔记和显式完整聊天课堂采用下面的**十个顶层教学章节，保持顺序与职责**；标题可随场景自然措辞，不能任意合并成自由布局。局部答疑按问题充分解释，无需硬套整课十章。阶段综合和显式短总结按其实际范围组织，不冒充完整源码课。

| 章 | 教什么、怎样展开 |
|---|---|
| 1 业务场景与本课目标 | 从一个具体动作/事件与实际问题开场，给明确输入和预期结果、读完会懂什么；业务词使用处先说明。 |
| 2 系统位置与架构分工 | 挂回系统地图，解释上下游、数据/状态归属、模块分工和为何放这里。图的节点、箭头与架构词先讲白话，不能只画类名链。 |
| 3 读懂本课所需的概念 | 必要基础写成教学小节：准确全称/中文 → 白话是什么 → 本项目为何需要 → 具体例子 → 易混区别 → 类比适用与失效之处。没有通行全称的项目名不编展开；词表只能导览。 |
| 4 端到端流程与本课边界 | 先看整条输入→处理→结果链，再标本课精读哪段、哪些仅接口边界和接续点。图随实际链路使用，静态追踪与运行观察分开。 |
| 5 真实源码逐段逐行精读 | 全课主体，按下文固定层次展开因果源单元。完整职责源码、代码后充分逐行正文与局部回放不能退化为几行代码加两句用途。 |
| 6 关键机制与官方资料解读 | 综合第五章的重要机制，进一步解释框架实际替项目做哪些步骤、如何成立与限制；消化已读适用版本官方规则，再逐点映射项目。必要时给明确标注的最小教学等价实现及省略边界，不重复字段说明或只列 URL。 |
| 7 同一组数据的正常与失败回放 | 将局部步骤拼成完整回放，列每次交接的具体对象/数组/条件/状态/返回与消费者；解释实际重要失败的停止点、残留状态和两端结果。 |
| 8 设计取舍与使用/扩展方法 | 对当前约束比较可行替代方案与代价，说明真实调用方式、修改影响与扩展接入。接口/插件追实现、装配/登记、触发和漏接后果，不只说“新增实现即可”。 |
| 9 易混淆点与带答案复习 | 针对本课表达式、机制或分支说明误读；问题紧跟充分答案和正文回指，供阅读自检，不要求先答才能继续。正式能力测验另按就绪规则。 |
| 10 本课收获、证据边界与下一课 | 总结实际能解释的因果关系，列未展开内部/未知/未运行边界与下一具体符号和问题；不把文章交付写成用户已掌握。 |

章节骨架防遗漏，标题齐全不等于讲透。每章写适合当前内容的实际教学，不制造不存在的失败、状态或插件。确实不适用的部分给简短具体理由，例如纯静态常量没有异常传播；不能借此豁免相关值含义、消费者或错值后果。

### 全景、配置、脚本与测试如何适配

第一节全景仍按十章认知次序，明确写“本课建立系统地图，尚未逐行追完实现”。第五章用实际 README/清单/入口/配置的有据片段解释组成和相互支持的证据，不假装精读代表链全部方法；第六章只教已核实机制，第七章可给标明静态/假设的业务流程示范，未核实支路保留未知。业务/系统图和实际仓库依据是此课主体，不堆虚假精读和失败。后续源码课恢复完整第五章展开。

配置课第五章换成完整相关配置与读取/绑定代码，追字段来源、优先级、生效时机、消费者和改错后果。脚本课追入口、工作目录、参数、控制流、输出/退出码及副作用；测试课追前置数据、动作、断言对象、为何能证明行为、模拟边界和漏测风险。简单字段、枚举、数据对象也以实际值追来源/合法含义/消费者和具体错误后果，避免字段字典；没有的机制不强造。

### 第五章：每个因果源单元的固定展开

按真实执行与理解依赖顺序反复使用以下层次，标题可以用本段真实问题命名，**层次和先后不可省**。单元通常是一整个方法、组件或内聚的完整职责，不是固定五行片段；必要的 import、字段、构造器、闭包/参数定义一并交代。

**第一层：现在遇到什么问题。** 给真实调用者、何时进入、同一具体输入、进入前状态和待解问题；变量来源交代到实参、属性解构、状态、外层闭包或局部定义。先补本段首次所需概念。

**第二层：真实完整源码。** 实际读取该版本文件，注明项目相对路径、符号、真实起止行和版本。贴完整方法或完整职责段，原语句保持原样，有意义语句/小语义组旁加准确且标明“教学”的注释；不适合内联的语言用紧邻原行说明。注释不能替代下一层正文。长方法可按连续原行分成带编号代码块，块间讲清衔接，保留全部相关语句与对应开闭；不反复拆成丢上下文的几行碎片。不强贴无关整文件，不靠“余下类似”省掉当前职责。省略须列真实范围、职责及不影响本目标的理由。

原行范围存在仍须核内容逐行相符。JSX、条件、try 结构不能删去真实中段后补造 `/>`、花括号或返回值冒充原文；教学改写单独标示。行号属于源文件，不是展示块编号。源码演进先区分历史真实版本与编造，旧片段不能按新版本无标记引用。

**第三层：代码之后的逐行正文。** 紧邻代码，以“原行 X：……”的小标题或自然段逐行/很小的有意义语义组展开，**贴出的所有源码行都须有对应解释，不能只挑关键行**。许可证、空行、重复纯闭合可合并交代，不能用大范围行组跨过真实语句，也不能为避开难行缩掉本职责必需源码。解释其中关键字、符号、类型、参数、表达式、分支、状态赋值、调用和 return：怎样读；具体值从哪来；定义还是现在执行；条件为何真/假；前后改变什么；返回给谁；为何需要；不用会怎样。按职责写足推导，不能把整个方法压成两句概述、字段名翻译或重复行内注释。简单对照可用小表，大段解释用连贯正文，避免宽表与电报体挤掉教学。

例如条件为 `!isThinking`，正文须解释 `isThinking` 的真/假、`!` 取反与谁更新值，不能偷换成“没有思考文本”。数组处理展示本例原数组、中间数组与结果，不能只说“处理两条旧消息”。一个生成方法若承接提示构建、渲染、请求、模型同步与回退，这些属于本课职责就完整展示并解释，不能只链接方法名；明确拆课时只声明接口边界与具体后课，不声称该机制已讲完。

**第四层：边界、副作用与本地回放。** 同一组输入代入刚讲语句，显示中间值、判断与返回。实际重要异常/回退分支在发生处讲：停止在哪行，状态是否已变，副作用是否发生。不存在失败不造；外部失败传播未查清，查必要调用处或明确未覆盖，不能声称完整失败教学。

**第五层：怎么用、上下游与实际接入。** 回到真实调用表达式解释传参/结果消费和下一个符号。可插入点给真实实现或清楚标示的最小教学实现，追谁创建、谁扫描/收集/登记、何时查找与触发；说明新增时必须新增/同步改哪些位置、漏接怎样表现。配置/纯数据对象追读取和生效，不硬套插件。这里收拢本单元用法，第八章再综合跨单元扩展步骤，不重复逐行正文。

### 执行机制与数据要讲到哪里

追定义→创建/注册→调用/回调→返回消费者，区分同步步骤、异步等待与恢复、类型声明与运行行为、内存状态与持久化。`async` 声明不证明调用方 `await`，调用方没 `await` 也不证明内部没有等待；分别读调用表达式、返回接收、Promise 链与内部等待。回调中 return 和外层返回各指向哪个消费者，不能混为一谈。

“框架自动”展开是谁、何时、根据项目哪个注册/扫描/启动点做哪几步。import 不自动等于创建或注册：Java 的 import 用于名称解析；JavaScript/TypeScript 运行时导入可能执行模块顶层初始化，类型专用导入须区分。生成构造器/getter/builder 查真实工具声明，不编成手写实现。状态改变到重新渲染、Effect（副作用处理）或回调，解释实际触发机制和条件。穿透到足以解释本课行为、取舍与重要失效模式，不无限扩成运行时手册。

贯穿数据具体且稳定：字段、字符串、数组顺序、布尔值和中间对象。假设数值标为教学例，之后沿用，静态推演不冒充日志。Why/替代方案用当前场景比较，例如省登记导致哪种输入找不到实现，而非“解耦/易维护”口号。最小等价实现标“教学示意，非项目原文”，说明省略的生产边界；不声称运行过，不强制每课另写框架。

源码、框架和底层的讲法须帮助读者作开发与架构判断：从当前问题推导实现思路，展开机制、设计约束、可行替代、边界和具体失败；有真实历史再讲演进，无历史则将未来改法明确标为设计推演。其他章节也以场景、因果、例子和判断依据展开，不能成为 API 辞典或几句章首概要。零基础铺垫与工程深度同时保留，不以高级名词代替深入。

## 官方资料如何进入教学

先读构建清单、锁文件/依赖声明及实际 import 来源，核适用版本；动态范围不是锁定版本。实际读维护者相关官方章节，必要时查依赖源码，以自己的话教**规则 → 机制 → 本项目具体语句映射 → 适用限制 → 直接章节链接**。第五章所需规则在介入前讲，第六章综合深挖，不能让读者自己查链接才懂。

访问不到或版本未确认，准确说明已核范围与未知，不用新版规则为旧依赖背书。通用文档不证明项目已注册/运行。链接不仅可打开，目标内容也须支持相邻断言：React 章节不能证明 Zustand，Zustand 不能证明 Virtuoso；本地锚点也核实际段落含义，不只验文件存在/行号在界内。

源码事实、官方规则、静态推断、假设例、真实观察和未知分清。课首说明整体证据范围，真正依赖未证实条件的断言旁限定，不每段重复同一句“未实测”。静态发送调用不能写成浏览器已收到，结尾免责也不能修正正文必然断言。作者动机无直接证据标推断。外部检索仅公开技术名/版本，不上传私人源码、标识或学习记录，不长篇复制版权文字。

## 返修保留教学内容

先有可恢复修前版本：可靠历史够用，无历史才留一次快照。修错、去实质重复和重组可以直接做，但原正确必要的概念/语法/机制、完整源段、具体值链、原因、正常/失败示例和官方映射须保留或已迁到可读目的位置。本课必要解释不能被“后面再讲”替代。无完整历史如实说明核对范围。

局部补缺只复读改动及影响上下游；广泛重写、源范围大变或影响不明才再全文通读。简记具体缺陷、修复位置、删改原因与真实未核项，不造逐段矩阵、教材 hash 或词数/章节数指标。同一字段解释不要再加“教学”标签重复抄一遍，保留有效正文并补机制。修订不能把详细教材缩成用途摘要。

## 教学就绪检查：何时可以提问

带答案复习是阅读材料，不是能力测验。正式预测/Quiz（测验）/复述前确认：前置已在实际交付教材/聊天充分解释，提供必要可读片段和上下文，用户愿意尝试；prepared、只提名称和假定读过都不够。问题诊断已教因果/修改影响，不让猜陌生字段成为推进门票。缺前置先讲，清旧 awaiting，`next_action=TEACH`；每轮不必测，能力 waiting 仍可继续教材。

“不会回答/一头雾水”先查漏讲或错序，保存原因/返回点，补缺而非换更小陌生题。只有已教后真实独立错误才记 gap。练习可从完整示范→愿意时带提示同类小步→就绪后独立变式→后续小实现，按真实表现减少支持。带提示成功不能称独立，也不替代最终 Mini Version；不代写用户复述。

## 首次需要时补齐阅读与操作基础

用当前真实文件解释仓库、项目根、目录/扩展名、相对路径、原行和符号，区分定义/调用、原文/新增教学注释。读者可自愿翻源码，不依赖其补正文。需操作时分清源码和终端命令，按实际系统/工具说明工作目录、参数/占位值、输出位置和相关报错定位，不默认会终端，也不强制安装才能只读学习。

## 发送前单轮交付自检

按 [作者流程](authoring.md#写出读懂并交付一节) 做一次语义通读，同时独立判断：**事实正确**（源段/版本/条件/值链/官方映射真）与**初学者可读**（必需概念在先、源码后逐句讲透、机制和例子能理解）。一个维度不能补另一个；审核者懂的知识不在文章里仍是缺漏。缺什么修正文，不写更大的通过报告；十章齐全、链接有效、篇幅长均不能证明质量。

完整稿补缺、必要 V0/保存/索引成功可 ready/self_review 并 delivered，真实独立审读范围才 validated；未完整/仍缺必要解释留 draft/prepared。交付与阅读均不提高 mastery，能力看真实学习者证据。默认聊天只主题、范围与链接，问题直接充分答疑。

## 知识桥梁、自由提问与实验

当前必要知识先教，真实阻塞/已证实误解进 KNOWLEDGE_DETOUR（知识绕行），按 [knowledge 模板](../assets/templates/knowledge.md) 保存白话、当前用途、深度、例子/陷阱和返回点；不把默认未知当失败。补齐后回主链，原题重新检查就绪。

自由提问立即解惑，局部问题不硬套十章。实质教材缺漏同步修对应文章/索引/进度，即时澄清不必重写整课。明确转开发保存学习返回点并尊重请求。实验按 Prediction → Modification → Run → Observe → Explain 记真实预测、授权、基线、命令/退出码、观察与清理，参见 [review 模板](../assets/templates/review.md)。无预测不伪造，未运行不验收 required 实验。

保护用户改动，优先隔离演示与最小有效检查；学习调用不授权安装、付费 API、有副作用服务或生产修改。已有授权可继续，缺必要授权只澄清具体动作，独立只读教学继续。实验/能力门禁按 [评估协议](evaluation.md)，持久化按 [记忆协议](memory.md)，记录不挤掉教材正文。
