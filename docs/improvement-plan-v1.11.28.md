本方案已落实当前共享指令与模板，基线仍为v1.11.27。当前只编辑raw parts，装配时自动渲染真实源码，累计审读后原字节复制发布；预览不参与装配。小勘误做补丁，教学不足用具体语义组/例值/保留范围驱动完整厚写。默认源码写法输入切为[完整单元示范](../deep-codebase-learning/references/source-unit-example.md)，旧整课示例按需参考；合同、数字与schema1不变，CLI捕获不是产品选项。

R23普通首用JS传输失败无稿；R24自动初稿/扩写达到2931行仍整课未过；R25集中返修2976行改善部分解释，仍非严格整课通过。R26经Root全文核对和4项集中修正，仅单元校准接受。机械raw直装已验证，不等于普通单会话完整课程稳定或快速通过；具体体量/耗时与边界见[最新验证记录](validation.md#当前结论试用版有已知验证限制)。以下是保留的设计依据及历史进展，不能将旧快照待验状态或工具流程当作当前用法。

历史r21/r22已冻结且不继续修成通过；r22量达2098行仍有源前后职责、真实类型/阶段、原码保真及state缺陷。现按真实内聚问题直接实例化canonical七个H4：最低state与Stage在首篇正文前建立；叙事与source include存原文part，已核本地raw经renderer生成原码/后置标题/链接与对象型source_refs，check_state只核结构，再确定性装配/审读/原字节发布。少量本地辅助不评分、不改变全部合同/数字；CLI捕获缩回ignored开发诊断，产品默认single及可选宿主子作者不变。历史负结果和r20无法证明原文完整恢复的限制保留，新普通请求尚待验收，不宣称提速、安装或发布，具体证据见验证记录。

此前r19普通请求已在无扩写/修稿提示下自动从首稿进入十章与源码单元展开，但§5.2重复同类普通字符串引号解析错误后按开发规则冻结FAIL；后续子批成功不改判。1308自然物理行/141593 bytes、十章标题只说明保存范围，E1/TEACH、最终review/V0及全篇教学审读仍未完成，不据输入变短断言缩水。一次有界Astra medium仅给方向设计：保留draft→expand→finalize及全部合同/原数字，分开语义产出与输入可靠性，不再加第三种载体技巧/脚本。原生入口只读核查未找到可确证切换当前host的配置，不改全局配置/工具/模型或以新工具为使用前提；具体证据及未知见验证记录。
目标是默认面对完全初学者，交付正式、详细、内容充足的中文笔记：当前理解所需的内容都讲明，没有明确事实错误。目标不是把每个词、每个 API 无限向下讲到完美。
以下保留原设计依据和任务边界；实际实施、历史试写及未完成范围以 [验证记录](validation.md#v11128-未发布候选边界) 为准。r5示范及r6冻结快照已有有界结构检查，不能代表整课教学通过；r6新稿关键事实改善但正式结构与源码教学仍失败。r7明确路由后普通首稿仍无项目源码且自审漏放；r8普通首稿已由Root完整读取585行并拒收，仍有职责混并、源码后浅讲、框架保证错推及状态合同未执行。r9仅具体化当前章任务、patch路径和既有JSON契约，待章级校准及普通请求验证；不修改失败目标教材，不据方案或结构检查声称效果已经改善。

## 1. 当前事实与改进对象

依据 [v27 实际验收记录](validation.md)，四课的总物理行数实测通过，但事实轴、教学轴均失败：

| 冻结课 | 实测总物理行 | 事实／教学 | 已知反例与含义 |
|---|---:|---|---|
| B-Flask-first | 2001 | FAIL／FAIL | 默认 Jinja Undefined 可输出空串，却被写成缺 username 必然模板报错；测试源码与单元完整性不足。 |
| C-Cobra-first | 2016 | FAIL／FAIL | 1770–1774 行虚构 `--path` flag；多个源码单元只有用途短段，完整用法不足。 |
| C-Flask-next | 2014 | FAIL／FAIL | 492 行把实际执行的 `add_url_rule` 注册调用说成未调用；1456 行说目录 OSError 使工厂退出，实际已有捕获。 |
| E-repeat | 2175 | FAIL／FAIL | 1457–1458 行错误声称工厂内部先读配置、后构造 Flask 应用对象 app；实际源码第 8 行先 `app = Flask(...)`，第 9–21 行再配置；1117 行把 `executescript` 名称解释为复数词；缺 `close_db` 关键源码。 |

总量不能抵消浅段、漏源码或错误推演。这里仅总行数有实测通过证据，未逐一精确统计小节 300／500 等展开目标，不能说各小节均已达标。

保存、恢复、局部问答、能力负门禁等有界场景已经实际执行；这与完整详细新课一次通过是不同结论。

C 收尾七处单行替换净零行，E 净增九行，没有大删；四课也没有同任务旧新版配对。因此不能推断“流程重导致缩水”或“v27 比旧版差”。

源码、概念、官方规则等要求原本已明确，主要问题是执行及审读没有真正落实。下一步应减少重复入口、让职责进入实际正文与事实核对，而不是继续堆积口号。

## 2. 研究依据及可用边界

以下资料已由本次设计研究阅读；实施时不要求作者每课重下、重读，也不把研究链接变成教学前置门禁。

所有字数下限都是用户偏好与工程试行，不是论文证明的科学最佳值。研究帮助选择方法，不能充当候选版已通过的证据。

## 3. 继承教学机制，不复制固定课表

借鉴 replicate-learning 的因果组织：真实具体业务镜头 → 当前职责完整源码 → 关键行贴近注释 → 块后充分解释 → 边界／副作用 → 调用现场、上下游与真实扩展注册。
保留当前动态路线：全景 → 能力 → 架构 → 数据准备／使用 → 具体端到端 → 逐层代码 → 其他能力／横向审计 → 独立重建。
不要求每课只走一条固定业务线，不把全仓每文件都讲成相同深度；全景、配置、资源课按已有适用职责处理，不为第五章假造实现。
概念复用“当前问题、白话、具体例、项目映射、易混边界”的机制；不做百科词表，也不以一个资料链接代替解释。
纯数据／配置也追实际读取者、何时生效和错值结果；组件解释到真实框架接入，不能止于文件用途。
不复制固定 17 章、每批全读整文件、大量工具、每项跑应用、每词百科或把阅读当能力的要求；不复制大量原文，不引入新的许可问题。

## 5. 量与内容预算

长期课程中每节默认正式教材，包括S00全景/单主题首课，保留至少2000正常物理行，复杂课按3000+准备，没有上限；作者自行拆课或选窄主题不能豁免。只有用户明确要求局部/单函数专题或明确短交付才用已有窄例外；局部正式教材免整课物理行线仍不免适用教学深度。全景不必追完所有实现，已展示源码仍须真实分组充分讲解。初稿不足留draft/prepared，继续同稿具体章/单元扩写；既有一次V0数量检查不足不能ready，不增加逐章审批或循环计数。
空行、机械断句、堆代码、题库、重复结论不负责凑量。先把缺失解释补进第五、三、六章，不在第九、十章尾部追加无关长问答填线。
保留现有试行展开量，不立刻普涨或降低数字：

| 位置 | 默认有意义中文解释正文 |
|---|---|
| 重要问题与实现思路 | 200 字以上 |
| 架构位置、触发与输入 | 200 字以上 |
| 每个首次解释的有意义语义组 | 300 字以上；复杂组 600 字以上 |
| 局部具体值运行与重要失败 | 300 字以上 |
| 核心机制与工程判断 | 500 字以上 |
| 用法、上下游、接入与修改影响 | 300 字以上 |
| 其他重要小节 | 250 字以上；核心架构／概念／机制／设计 500 字以上 |

新核心概念按 500 字级展开；必要非核心术语在首次影响理解处随当前句解释，不能只给全称、词典定义或拖到后文。括号、逗号、纯闭合不逐个强塞 500 字。
源码定位、纯import/重复闭合声明、结尾短导航不凑数字；充分旧文局部返修与精确复用已充分机制的边界保留。r5将新稿首次行为300字/复杂600字明确为实际起稿下限，不能以“已经充分”或“简单”泛化豁免；精确复用仍解释本次值与差异，新行为不随之豁免。这是用户偏好与工程约束，不是科学最优值或语义质量证明。
只在一次 V0 中用已有工具统计总行数；小节量在同一次语义通读粗核，不逐段反复计数，不增评分器。未实测就不写“逐小节全部达标”。
不强制第五章先写；v25 已试过该顺序，下一版内部写作顺序由作者安排。

## 6. 十章正文的具体落法

下表同时列当前观察及下一版任务。当前观察不代表每一课的每一小节都失败；全章适用职责仍须在审读中逐项核实。

| 章 | 当前观察 | 下一版保留并落实的全部适用任务 |
|---|---|---|
| 1 业务场景与目标 | 多篇已有具体业务场景和固定输入，但不能由此放行其他章。 | 真实人、操作、输入、原始困难、怎样解决、成功结果、当前边界；给可追的具体值。 |
| 2 系统位置与架构 | 文件职责名称不能替代运行边界与交接。 | 真实运行边界图、路径／符号、角色输入输出、谁创建／持有、生命周期、协作载体及边界设计原因。 |
| 3 必需概念 | 全称／必要前置与规则例值展开不齐；名称出现不代表教过。 | 每个核心概念按当前困难 → 通行全称／中文白话 → 具体使用及例值 → 项目代码／框架规则 → 相近概念和设计含义；首次先短释，此处再深化。 |
| 4 端到端流程 | C 续／E 已有 CLI 与 HTTP 区分及时序图，但跨章重述仍出现与真实控制流矛盾。 | 分开启动装配与每次动作；同一组值从真实入口追到返回及调用者／界面／终端，说明重要失败和本课范围。 |
| 5 源码精读 | 多个 5.x 是用途摘要；有改写未声明、必要源码缺失。 | 每个实际动作单元完整八职责，真实源码、紧邻逐组正文、具体调用值与必要机制，详见下一节。 |
| 6 关键机制与官方资料 | Cobra 第六章有具体官方规则映射，E 第六章却变成流程再回放，机制深度不齐。 | 难机制问题 → 实读适用官方具体规则 → 框架何时接管及注册／查找／分派 → 项目表达式和例值 → 证明范围、未知、直接链接。 |
| 7 正常与失败回放 | Cobra 有停点／残留表，E 第七章改成泛论测试，不能替代当前完整值链与重要失败演算。 | 固定输入和完整对象 → 正常链 → 重要失败停点 → 残留副作用、消费者和两端结果；不让每章重复整条流程。 |
| 8 设计与使用扩展 | Cobra 用纸上练习、E 用失败分类替代完整使用教程。 | 环境材料、命令／真实操作、期望信号、排错、一个改动的真实接线、同条件可行替代；示例操作与实际执行分开标明。 |
| 9 易混与复习 | Cobra 第九章 1770–1774 行误教不存在的 --path；其他长问答不能补前文缺讲。 | 来自真实疑问或明确假设误读；答案有具体推导与例值，不伪造真人回答。 |
| 10 收获与下一课 | 交付、自评与能力状态不能互相替代。 | 因果收获、实际覆盖、证据／未知、下一具体目标和符号；短导航不硬凑 500 字，不批量升 mastery。 |

单进程、无前端项目无需硬造多层嵌套、浏览器或网络返回，应追真实终端／调用者结果。无复杂架构或未运行，不是必要语句可以浅讲的豁免。
未 pin 运行版本不等于不能教学已核官方规则：应明确版本条件与证明边界，不假称已运行验证。

## 7. 第五章每个 5.x 的可落稿形状

按真实动作切单元，不按每文件或任意五行分组；每单元保留八职责：

- 1. 具体问题与实现思路。
- 2. 架构位置、真实触发与输入准备。
- 3. 源码定位及必要阅读准备。
- 4–5. 当前职责连续源码与紧邻正文交替，区分原码与教学注释；每个源块后立即按真实原行小组充分展开，再继续下一块。
- 6. 同输入局部运行、边界及重要失败。
- 7. 机制与工程判断。
- 8. 怎么用、上下游、真实接入及修改影响。

八项教学职责采用七个写作位置：第4–5项必须同一区域连续交替，不再分成完整代码与逐句推导两块，其余六项各有位置，不能被章末综述吞掉。5.x以真实符号/行为命名，每单元各有八职责，不将整课5.1–5.8当作共用职责；紧密合作的内聚职责可同单元，独立因果问题分别展开，不机械一函数一单元。完整方法在合理行为边界以连续切片累计保留，须保留作用域、变量来源、分支闭合、衔接及省略边界，不能删当前必要难行；真正一个语义组可一块，多独立动作交替，不设块行数上限。
每个源块后立即以原行 X／小组落段，承担三层内容，而非每行固定三张表或八问：

- 怎样读：关键字、符号、类型、变量来源、当前实际表达式如何求值。
- 怎样运行：同一具体值的调用者、时机、实参／形参、返回接收、状态改变及后续消费者。
- 为什么成立：当前语言／API／框架规则，失败停止与副作用，改法对行为及工程取舍的实际影响。

纯闭合可并入前组，所有有意义行都须覆盖。只加注释、原行标题、用途简述，或有函数名却没有具体调用值，均不合格。
定位包括真实路径、符号、原行、版本及可点击源定位；教学注释必须可辨识，不能悄悄改写原码。
调用现场、上下游、扩展注册使用真实项目代码；决定当前对象、类型、状态或控制结论的最小完整生产者、登记/适配及调用/回调消费者须实际展示并教清，路径与用途不算实现，不要求追无关整套框架。小型教学等价片段显式写成示意，不冒充项目原文。来源对照含项目和外部原文件切片的范围、语句、原注释与空行；官方规则可用有效章节/符号直链，不虚构网页抽取行锚点。
高级视角来自所有权、职责、故障及替代条件的推导，不能靠“解耦”等高级词代替解释。
