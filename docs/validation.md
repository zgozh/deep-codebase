## 本地结构检查

Python 3.10+用于维护者检查，不是Skill运行依赖：

```bash
python -m pip install -r requirements-dev.txt
python scripts/validate.py
```

检查name/description/version/许可证、UI调用元数据、JSON与YAML、初始状态/概念模板字段、Markdown本地文件/锚点链接、UTF-8、占位残留与发布路径范围。脚本只读发布文件；输出PASS不代表模型教学行为已验证。

CI使用相同命令。安装发现还可检查：

```bash
npx skills add . --list
```

这只列出Skill，不写目标Agent安装目录。真正安装与跨Agent行为应分别验证，不能从CLI发现成功推断兼容性。

小规模评测方法：固定真实源码commit、完整课因果目标、输入/前置、模型与推理档位、宿主/权限和交付深度；候选与已知旧版基线各在隔离上下文用同一任务执行，核实际加载版本。代表任务可组合完整十章真实课、不同语义形态（如异步状态/回调与同步配置/存储）及已有稿定点返修或错误放行挑战；本轮实际范围见下文。不以不同功能的笔记KB比较，不规定每次修改跑全套；先约定重要事实与教学失败边界。

新旧产物匿名打乱交独立审读，提供任务、正文、源码和必要官方证据，不给预期结论或作者自评。事实准确与初学者能否据正文恢复语法、绑定、状态、消费者及机制分别判断；完整课实际覆盖所有章与单元，不能用一个好例子放行。真实初学者反馈仍是可读性和学习实效的重要证据，模型评分不能代替。校准例子不是尺寸上限，外部研究不授权删十章、展开基线或当前必要源码解释。

效率从已有日志读取，不加运行埋点：首次完整可读稿用时、晚期返工、同类失败重试/重复读取、总活跃区间及实际完成范围；委派等待与并行区间不累加，容量、网络等环境故障另记。提速须同时保留完整必要源码和教学，否则不接受。现有V0只核格式、链接、JSON等，不自动评分语义，也不新增关键词或计数判优工具。先配对定位问题，稳定性或提速结论需要更多独立重复，报告样本与失败，单次优稿不称稳定。本轮配对及后续定点修稿仅支持下述具体观察，不替代真实初学者反馈。
